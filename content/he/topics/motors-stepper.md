# מנוע צעד

**מנוע צעד** (stepper motor) לא מסתובב בצורה חלקה. הוא זז ב**צעדים קטנים ומדויקים**, ועוצר במקום אחרי כל צעד. אמרו לו "200 צעדים" והוא יזוז בדיוק 200 צעדים. ספרו את הצעדים ותדעו בדיוק איפה הוא נמצא, בלי שום חיישן. בגלל זה מנועי צעד מזיזים את ראש ההדפסה במדפסת תלת-ממד, את העדשה במצלמה ואת הסורק במכונת צילום.

מנוע הצעד שתמצאו ברוב ערכות המתחילים הוא ה-**28BYJ-48**, שמגיע עם לוח דרייבר קטן מסוג **ULN2003**.

## איך זה עובד

בפנים, מגנט (ה**רוטור**, rotor) יושב באמצע בין כמה **סלילים**. מדליקים סליל אחד והמגנט מסתובב כדי לפנות אליו. מכבים את הסליל הזה ומדליקים את הבא, והמגנט מסתובב שוב, בצעד אחד:

![ארבע תמונות מצב: סליל A דולק, אחר כך B, אחר כך C, אחר כך D; בכל פעם המגנט שבאמצע מסתובב כדי לפנות לסליל הדולק](assets/motors/stepper-inside.svg)

- מדליקים את הסלילים **לפי הסדר** (A, B, C, D, A, …) והמנוע מסתובב לכיוון אחד.
- מדליקים אותם **בסדר ההפוך** והוא מסתובב לכיוון השני.
- מחליפים ביניהם **מהר יותר** והוא מסתובב מהר יותר.
- **מפסיקים להחליף** והמנוע עוצר ומחזיק את המקום שלו.

למנוע צעד אמיתי יש הרבה יותר "שיניים" מאשר בציור שלנו, ולכן הצעדים שלו הרבה יותר קטנים. ל-28BYJ-48 יש גם תיבת הילוכים בפנים: הוא צריך בערך **2048 צעדים לסיבוב שלם אחד** של הציר. זה פחות מ-0.2° לצעד.

## חיבור מנוע צעד ל-Arduino Nano ESP32

הסלילים צריכים הרבה יותר זרם ממה שפין יכול לתת, ולכן ארבעת הפינים הולכים לדרייבר **ULN2003**, שמדליק ומכבה את הסלילים בשבילנו. המנוע מתחבר לשקע הלבן שעל לוח הדרייבר (הוא נכנס רק בכיוון אחד):

![הפינים D2 עד D5 של ה-Nano ESP32 הולכים ל-IN1 עד IN4 של לוח ה-ULN2003; VBUS הולך ל-+ ו-GND ל-−; המנוע מתחבר ללוח](assets/motors/stepper-wiring.svg)

| לוח ULN2003 | מתחבר ל- |
|---------------|------------|
| **IN1, IN2, IN3, IN4** | **D2, D3, D4, D5** של ה-Nano |
| **+** | **VBUS** של ה-Nano (5 V) |
| **−** | **GND** של ה-Nano |

ארבע הנורות הקטנות (LED) על לוח הדרייבר מראות איזה סליל דולק. כשהמנוע מסתובב לאט, אפשר לראות אותן נדלקות בתורן.

> **טוב לדעת:** מנוע צעד צורך זרם גם כשהוא עומד במקום, כי סליל נשאר דולק כדי להחזיק את המיקום. ה-28BYJ-48 מתחמם, וזה נורמלי. מנועי צעד גדולים יותר (כמו ה-NEMA 17 במדפסות תלת-ממד) צריכים ספק כוח משלהם ודרייבר אחר, כמו ה-A4988.

## הקוד

הספרייה **Stepper** מגיעה עם ה-Arduino IDE, אז אין מה להתקין:

```c
#include <Stepper.h>

const int STEPS_PER_TURN = 2048;   // for the 28BYJ-48

// Watch the order: IN1, IN3, IN2, IN4. This is what the 28BYJ-48 needs.
Stepper motor(STEPS_PER_TURN, D2, D4, D3, D5);

void setup() {
  motor.setSpeed(10);   // in turns per minute (rpm); 28BYJ-48: up to about 15
}

void loop() {
  motor.step(STEPS_PER_TURN);        // one full turn one way
  delay(1000);
  motor.step(-STEPS_PER_TURN / 4);   // a quarter turn back (negative = other way)
  delay(1000);
}
```

שני דברים ששווה לשים לב אליהם:

- סדר הפינים ב-`Stepper motor(...)` הוא **D2, D4, D3, D5**, ולא D2, D3, D4, D5. עם הסדר ה"טבעי" המנוע רק רועד ומזמזם. זו מוזרות ידועה של ה-28BYJ-48 עם הספרייה הזאת.
- `motor.step()` **מחכה** עד שכל הצעדים מסתיימים. בזמן שהמנוע מסתובב, שאר התוכנית שלכם עומדת.

## סיכום

- **מנוע צעד** מסתובב ב**צעדים** מדויקים על ידי הדלקת הסלילים שלו אחד אחרי השני. ה-28BYJ-48 צריך בערך 2048 צעדים לסיבוב ודרייבר ULN2003.

## אתגרים

1. **מחוג שעון:** הדביקו חץ מנייר לציר של מנוע הצעד וגרמו לו לזוז כמו מחוג השניות של שעון: צעד אחד של 6° (2048 / 60 ≈ 34 צעדים) בכל שנייה.
2. **שליטה בכפתורים:** השתמשו בשני כפתורים (ראו "Buttons Advanced") כדי לסובב את מנוע הצעד קצת שמאלה או קצת ימינה בכל לחיצה.
