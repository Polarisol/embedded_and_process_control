# מחרוזות למתקדמים

ביסודות שפת C השתמשתם ב-`printf` כדי לכתוב טקסט על המסך וב-`scanf` כדי לקרוא את מה שהמשתמש מקליד. לכל אחת מהן יש קרובת משפחה שעושה את אותה עבודה עם **מחרוזת** במקום המסך או המקלדת:

| פונקציה | מה היא עושה | המקבילה ב-Python |
|----------|--------------|-------------------|
| `printf` | כותבת טקסט מעוצב ל**מסך** | `print(f"...")` |
| `sprintf` | כותבת טקסט מעוצב **לתוך מחרוזת** | `s = f"..."` |
| `scanf` | קוראת ערכים מה**מקלדת** | `int(input())` |
| `sscanf` | קוראת ערכים **מתוך מחרוזת** שכבר יש לכם | `line.split()`, ואז `int()` ו-`float()` |

שתי הפונקציות האלה הן הדרך שבה תוכנית C **בונה** הודעת טקסט לשליחה ו**מפרקת** הודעת טקסט שהתקבלה. זה רוב מה שהתקן מכטרוני עושה כשהוא מדבר עם מחשב.

שתיהן נמצאות ב-`stdio.h`, ושתיהן משתמשות בקודי העיצוב שאתם כבר מכירים (`%d`, `%f`, `%c`, `%s`).

## `sprintf`: טקסט מעוצב לתוך מחרוזת

`sprintf` היא `printf` עם ארגומנט נוסף אחד בהתחלה: המחרוזת שאליה כותבים.

```c
sprintf(string, "format text", values...);
```

כל מה שאחרי הארגומנט הראשון עובד כמו ב-`printf`. שום דבר לא מופיע על המסך. הטקסט נכנס למחרוזת, מוכן לשימוש:

```c
char message[32];
int speed = 150;

sprintf(message, "Speed: %d rpm", speed);

printf("%s\n", message);     // prints: Speed: 150 rpm
```

`sprintf` שמה בשבילכם את ה-`'\0'` הסוגר בסוף הטקסט.

> **זהירות:** `sprintf` לא יודעת מה גודל המערך. אם הטקסט ארוך מדי, היא ממשיכה לכתוב מעבר לסוף והורסת את מה שנמצא שם. מערך בגודל 32 מכיל לכל היותר 31 תווים ואת ה-`'\0'`. תנו למערך גודל שמספיק להודעה הארוכה ביותר שאתם מצפים לה, עם המספרים הגדולים ביותר.

### שליטה בעיצוב

התקן שקורא את ההודעה שלכם מצפה לפריסה מדויקת, ולכן האפשרויות האלה של `printf` חשובות כאן יותר מאשר על המסך:

| קוד | משמעות | ערך | הטקסט שנוצר |
|------|---------|-------|---------------|
| `%d` | מספר שלם | `42` | `42` |
| `%5d` | רוחב של לפחות 5 תווים, מרופד ברווחים | `42` | `   42` |
| `%05d` | רוחב של לפחות 5 תווים, מרופד באפסים | `42` | `00042` |
| `%.2f` | 2 ספרות אחרי הנקודה העשרונית | `3.14159` | `3.14` |
| `%7.2f` | רוחב 7 תווים, 2 אחרי הנקודה | `3.14159` | `   3.14` |
| `%X` | מספר שלם בהקסדצימלי | `255` | `FF` |
| `%02X` | הקסדצימלי, 2 תווים, מרופד באפסים | `10` | `0A` |
| `%%` | סימן אחוז אמיתי | | `%` |

### חיבור מחרוזות

`%s` שם מחרוזת אחת בתוך אחרת, כך ש-`sprintf` היא גם דרך פשוטה לחבר מחרוזות ומספרים למחרוזת אחת:

```c
char name[] = "TEMP";
char unit[] = "C";
float value = 23.5;
char text[32];

sprintf(text, "%s = %.1f %s", name, value, unit);    // text = "TEMP = 23.5 C"
```


## `sscanf`: קריאת ערכים מתוך מחרוזת

`sscanf` היא `scanf` עם ארגומנט נוסף אחד בהתחלה: המחרוזת שממנה קוראים. היא לא מחכה למקלדת.

```c
sscanf(string, "format text", &variable1, &variable2...);
```

```c
char line[] = "150 2.5";
int speed;
float gain;

sscanf(line, "%d %f", &speed, &gain);    // speed = 150, gain = 2.5
```

החוקים של `scanf` עדיין תקפים: `&` לפני משתנים פשוטים, בלי `&` לפני מחרוזת, ו-`%lf` בשביל `double`.

### טקסט קבוע בפורמט

כל טקסט רגיל בפורמט חייב להופיע במחרוזת בדיוק כפי שהוא כתוב. כך אפשר לתאר את ההודעה כולה:

```c
char line[] = "TEMP 23.5 HUM 40";
float temp;
int hum;

sscanf(line, "TEMP %f HUM %d", &temp, &hum);    // temp = 23.5, hum = 40
```

רווח בפורמט מתאים לכל מספר של רווחים במחרוזת, כך שגם `"TEMP   23.5 HUM 40"` עובד.

### תמיד בדקו את ערך ההחזרה

`sscanf` מחזירה **כמה ערכים היא הצליחה לקרוא**. היא עוצרת בדבר הראשון שלא מתאים, והמשתנים שהיא לא הגיעה אליהם שומרים על הערכים הישנים שלהם.

```c
int n = sscanf(line, "TEMP %f HUM %d", &temp, &hum);

if (n == 2) {
    printf("Temperature %.1f, humidity %d\n", temp, hum);
} else {
    printf("Bad message: %s\n", line);
}
```

| `line` | `n` | למה |
|--------|-----|-----|
| `"TEMP 23.5 HUM 40"` | 2 | שני הערכים נקראו |
| `"TEMP 23.5 HUM abc"` | 1 | `abc` הוא לא מספר |
| `"TEMP 23.5"` | 1 | ההודעה נגמרה מוקדם |
| `"SPEED 100"` | 0 | הטקסט `TEMP` לא נמצא |

> **זהירות:** הודעה שמגיעה בחוט יכולה להיקטע או להיפגע מרעש. אם תדלגו על הבדיקה, הודעה פגומה תשאיר **ערכים ישנים או ערכי זבל** במשתנים שלכם, והמנוע שלכם יפעל לפיהם. השוו את ערך ההחזרה למספר הערכים שאתם מצפים לו, בכל פעם.

### קריאת מילה ומספר

כדי לקרוא שם של פקודה, השתמשו ב-`%s` עם הגבלת גודל, ואז השוו אותו עם `strcmp`:

```c
char line[] = "SPEED 150";
char command[10];
int value;

if (sscanf(line, "%9s %d", command, &value) == 2) {
    if (strcmp(command, "SPEED") == 0) {
        printf("Set the speed to %d\n", value);
    } else if (strcmp(command, "ANGLE") == 0) {
        printf("Turn to %d degrees\n", value);
    }
}
```

ה-`9` ב-`%9s` הוא הגודל של `command` פחות אחד, מה שמשאיר מקום ל-`'\0'`.

> **זהירות:** `%s` קורא עד הרווח הבא, ופסיק הוא לא רווח. ב-`"SPEED,150"` ה-`%s` לוקח את כל ה-`SPEED,150` ולא נשאר כלום בשביל `%d`. הפתרון הפשוט הוא להפריד בין חלקי ההודעה ב**רווחים**. פסיקים בין מספרים זה בסדר: `"%d,%d"` קורא את `"10,20"` נכון.

## שימוש בתקשורת מכטרונית

מערכת מכטרונית היא כמעט אף פעם לא תוכנית אחת. PC מדבר עם בקר מנוע, מיקרו-בקר מדבר עם מודול GPS, כרטיס חיישנים מדווח למערכת רישום. הם מחוברים בקו טורי (ראו **תקשורת טורית**) שמעביר **בתים**, אחד אחרי השני, ותו לא.

דרך נפוצה מאוד לתת לבתים האלה משמעות היא לשלוח **שורות של טקסט**:

```
PC          ->  controller :   SPEED 150\n
PC          ->  controller :   READ\n
controller  ->  PC         :   TEMP 23.5 HUM 40\n
```

כל שורה היא מחרוזת. כל צד צריך אז שתי מיומנויות, והן שתי הפונקציות שבעמוד הזה:

| משימה | פונקציה |
|-----|----------|
| להפוך מספרים להודעת טקסט, מוכנה לשליחה | `sprintf` |
| להפוך הודעת טקסט שהתקבלה בחזרה למספרים | `sscanf` |

איך המחרוזת עוברת בחוט תלוי בלוח שלכם ומוסבר במקום אחר. העמוד הזה עוסק במחרוזת עצמה.

### למה טקסט?

- **אפשר לקרוא אותו.** חברו מסוף טורי (serial terminal) ותראו `TEMP 23.5 HUM 40`, ואפשר להקליד פקודות ביד כדי לבדוק התקן עוד לפני שתוכנית ה-PC קיימת
- **כל שפה יכולה לדבר אותו.** סקריפט Python, תוכנית C ופאנל LabVIEW יכולים כולם לדבר עם אותו בקר
- **שני הצדדים מסכימים על המספרים.** הטקסט `150` אומר אותו דבר בכל מעבד, בעוד שהבתים שבתוך `int` שונים ממכונה למכונה

המחיר הוא גודל. המספר `23.5` הוא 4 תווים, ובמסגרת 8N1 כל תו עולה 10 ביטים על הקו. ב-9600 באוד זה בערך 960 תווים בשנייה, כך שהודעה של 20 תווים יכולה להישלח לכל היותר 48 פעמים בשנייה. בלולאות בקרה מהירות, מהנדסים עוברים להודעות בינאריות.

### שליחה: בונים את ההודעה עם `sprintf`

```c
char message[32];
float temp = 23.5;
int hum = 40;

sprintf(message, "TEMP %.1f HUM %d\n", temp, hum);    // message = "TEMP 23.5 HUM 40\n"
```

המחרוזת `message` מוכנה עכשיו, ואתם מעבירים אותה לפונקציית השליחה שיש בלוח שלכם, מה שזה לא יהיה.

> **זהירות:** במיקרו-בקרים קטנים, `%f` מבוטל לעיתים קרובות כדי לחסוך בזיכרון, והוא מדפיס `?` או כלום. טריק נפוץ הוא לשלוח מספר שלם ביחידות קטנות יותר: שולחים `235` ומסכימים שזה אומר עשיריות מעלה.

### קבלה: מפרקים את ההודעה עם `sscanf`

ברגע ששורה שלמה הגיעה ויושבת במחרוזת, פרקו אותה עם `sscanf` ובדקו את ערך ההחזרה:

```c
char line[] = "TEMP 23.5 HUM 40\n";
float temp;
int hum;

if (sscanf(line, "TEMP %f HUM %d", &temp, &hum) == 2) {
    // temp and hum are safe to use
}
```

לעולם אל תריצו `sscanf` על חצי הודעה. ה-`'\n'` בסוף הוא מה שאומר למקלט שההודעה שלמה, ובגלל זה כל הודעה בפרוטוקול מסתיימת בו.

### דוגמה מלאה

התוכנית הזו היא הצד של הבקר בפרוטוקול שלמעלה. הפונקציה `handle` מקבלת פקודה אחת כמחרוזת ומפרקת אותה עם `sscanf`. `SPEED` קובעת את המהירות, ו-`READ` בונה תשובה עם `sprintf`. כאן `main` מזינה לה כמה פקודות בדיקה ומדפיסה את התשובה, כך שאפשר להריץ את זה על כל מחשב. בהתקן אמיתי, הפקודות מגיעות מהקו הטורי והתשובה חוזרת אליו, ו-`handle` נשארת אותו דבר.

```c
#include <stdio.h>
#include <string.h>

int speed = 0;
float temp = 23.5;
int hum = 40;

void handle(char line[])
{
    char command[10];
    char reply[40];
    int value;

    int n = sscanf(line, "%9s %d", command, &value);

    if (n == 2 && strcmp(command, "SPEED") == 0) {
        speed = value;
    } else if (n >= 1 && strcmp(command, "READ") == 0) {
        sprintf(reply, "TEMP %.1f HUM %d SPEED %d\n", temp, hum, speed);
        printf("%s", reply);
    }
}

int main(void)
{
    handle("SPEED 150\n");
    handle("SPEED fast\n");
    handle("JUMP 5\n");
    handle("READ\n");

    return 0;
}
```

רק `READ` שולחת תשובה, ולכן התוכנית מדפיסה שורה אחת:

```
TEMP 23.5 HUM 40 SPEED 150
```

שימו לב לפקודה השנייה. `fast` הוא לא מספר, ולכן `sscanf` מחזירה 1, הבדיקה `n == 2` נכשלת ומתעלמים מהפקודה. המהירות נשארת 150. `JUMP` היא לא פקודה מוכרת, ולכן גם ממנה מתעלמים.

### לתכנן הודעות משלכם

- **סיימו כל הודעה ב-`'\n'`**, כדי שהמקלט ידע איפה היא נגמרת
- **התחילו בשם** (`SPEED`, `TEMP`), כדי שהמקלט ידע איזה סוג הודעה זו
- **הפרידו בין החלקים ברווחים**, ש-`sscanf` מטפלת בהם היטב
- **קבעו את היחידות** וכתבו אותן: האם `150` הוא ב-rpm או באחוזים?
- **בדקו את ערך ההחזרה של `sscanf`** והתעלמו מכל הודעה שלא מתאימה
