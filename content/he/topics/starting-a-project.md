# התחלת פרויקט

בצעו את השלבים האלה בכל פעם שאתם מתחילים פרויקט חדש. הם מניחים שכבר עשיתם את כל מה שמופיע בפרק **התקנה** (Installation).

## 1. יצירת תיקיית עבודה

צרו תיקייה חדשה וריקה לפרויקט, למשל `Documents\Projects\my-first-project`.

> טיפ: תנו לתיקייה שם קצר בלי רווחים ובלי אותיות שאינן באנגלית (למשל `my-first-project`). חלק מהכלים מתבלבלים מהם.

## 2. פתיחת התיקייה ב-VS Code

כל אחת מהדרכים האלה עובדת:

- בסייר הקבצים (File Explorer), לחצו לחיצה ימנית על התיקייה ובחרו **Open with Code**. (האפשרות הזו מופיעה רק אם סימנתם את התיבות "Add Open with Code" בהתקנת VS Code.)
- או פתחו את VS Code, בחרו **File → Open Folder…**, ואז בחרו את התיקייה.

## 3. מתן אמון בתיקייה

תיקייה חדשה נפתחת **במצב מוגבל** (Restricted Mode): פס הודעה בראש החלון אומר את זה, ותגית *Restricted Mode* מופיעה בשורת המצב בתחתית. במצב הזה VS Code חוסם את הטרמינל ומכבה את התוספים של Python ו-Jupyter, כך שעדיין אי אפשר להריץ שום דבר.

כדי לתת אמון בתיקייה:

1. לחצו על **Manage** בפס ההודעה (או על התגית *Restricted Mode* בשורת המצב). ייפתח עמוד ה-Workspace Trust.
2. לחצו על **Trust**.

פס ההודעה נעלם והכול עובד. VS Code זוכר את הבחירה שלכם, כך שעושים את זה רק פעם אחת לכל תיקייה.

> טיפ: אפשר לתת אמון **בתיקיית האב** במקום זאת (למשל `Documents\Projects`). כך כל פרויקט שתיצרו בתוכה יקבל אמון אוטומטית. תנו אמון רק בתיקיות שאת התוכן שלהן יצרתם בעצמכם או שאתם יודעים שהוא בטוח.

## 4. פתיחת הטרמינל

בחרו **View → Terminal** (או לחצו ``Ctrl+` ``). בתחתית החלון ייפתח טרמינל, שכבר נמצא בתוך תיקיית הפרויקט שלכם.

## 5. יצירת הפרויקט עם uv

בטרמינל, כתבו:

```bash
uv init --python 3.12
```

החליפו את `3.12` בגרסה אחרת אם הפרויקט שלכם צריך כזו.

הפקודה הופכת את התיקייה לפרויקט Python. היא יוצרת:

- `pyproject.toml`: ההגדרות של הפרויקט, כולל רשימת הספריות שהוא משתמש בהן
- `.python-version`: גרסת ה-Python שהפרויקט משתמש בה
- `main.py`: תוכנית דוגמה קטנה
- `README.md`: מקום לתאר בו את הפרויקט שלכם

**אם git מותקן**, `uv init` גם הופך את התיקייה למאגר (repository) של git (עם קובץ `.gitignore`), כך שתוכלו לעקוב אחרי השינויים שלכם ולהעלות את הפרויקט ל-GitHub בהמשך.

## 6. הוספת ספריות

הוסיפו את הספריות שהפרויקט שלכם צריך, למשל:

```bash
uv add jupyter numpy matplotlib
```

בפעם הראשונה שמריצים את זה, uv יוצר תיקיית `.venv` (סביבת ה-Python הפרטית של הפרויקט) ומתקין לתוכה את הספריות. הוא גם רושם אותן ב-`pyproject.toml`.

- צריכים ספרייה נוספת אחר כך? הריצו שוב `uv add` מתי שתרצו, למשל `uv add pandas`.
- הוספתם משהו שאתם לא צריכים? הסירו אותו עם `uv remove`, למשל `uv remove pandas`.

## 7. כתיבה והרצה של קוד

אפשר לכתוב קוד בקובץ Python רגיל או במחברת (notebook) של Jupyter.

### קובץ Python (`.py`)

1. צרו קובץ עם סיומת `.py` (למשל `hello.py`), או פתחו את `main.py`.
2. כתבו את הקוד שלכם, למשל:

   ```python
   print("Hello, world!")
   ```

3. הריצו אותו עם **Ctrl+F5**. הפלט מופיע בטרמינל.

> בהרבה מחשבים ניידים מקשי ה-F שולטים כברירת מחדל בעוצמת הקול או בבהירות. אם Ctrl+F5 לא מריץ את הקוד שלכם, החזיקו גם את מקש ה-**Fn**: **Ctrl+Fn+F5**. אפשר גם ללחוץ על הכפתור **▷ Run Python File** בפינה הימנית העליונה של העורך.

### מחברת Jupyter (`.ipynb`)

זה עובד רק אם הוספתם את `jupyter` בשלב 6.

1. צרו קובץ עם סיומת `.ipynb` (למשל `explore.ipynb`).
2. כתבו קוד בתא (cell).
3. הריצו את התא עם **Shift+Enter**. הפלט מופיע ממש מתחתיו, ו-VS Code עובר לתא הבא (ומוסיף תא חדש אם אתם בתא האחרון).

### ההרצה הראשונה: בחירת המפרש (interpreter)

בפעם הראשונה שמריצים קוד בקובץ, VS Code שואל באיזה Python להשתמש:

- עבור **קובץ `.py`**, הוא עשוי לבקש קודם לבחור מנפה שגיאות (debugger). בחרו **Python Debugger**, ואז **Python File**. אם הוא מבקש מפרש, בחרו את זה שיש בשם שלו **`.venv`** (בדרך כלל הוא מסומן *Recommended*). אפשר גם לבחור אותו בעצמכם בכל זמן עם הפקודה **Python: Select Interpreter** (Ctrl+Shift+P, ואז הקלידו אותה).
- עבור **מחברת**, הוא מבקש **Select Kernel** (הכפתור נמצא בפינה הימנית העליונה של המחברת). בחרו **Python Environments…**, ואז את זו שיש בשם שלה **`.venv`**.

תמיד בחרו את זו של `.venv`. זו הסביבה הפרטית של הפרויקט, והיחידה שיש בה את הספריות שהוספתם עם `uv add`. אם תבחרו אחרת, תקבלו שגיאות כמו `ModuleNotFoundError: No module named 'numpy'`.

כדי לשנות את זה אחר כך, לחצו על גרסת ה-Python שמוצגת בפינה הימנית התחתונה של VS Code (עבור קובץ `.py`) או בפינה הימנית העליונה של מחברת.
