# סקירה של Nano ESP32

ה-**Arduino Nano ESP32** הוא לוח הפיתוח שבו אנחנו משתמשים בקורס. הוא קטן מספיק כדי לשבת על מטריצה (breadboard), עולה בערך כמו פיצה, ויש בו כל מה שצריך כדי לבנות פרויקטים אמיתיים: מעבד מהיר, הרבה זיכרון, ו-**Wi‑Fi** ו-**Bluetooth** מובנים.

הוא מחבר יחד את שתי המשפחות מהמבוא. **Arduino** ייצרו את הלוח, עם הכלים הפשוטים והקהילה הענקית שלהם. השבב שעליו הוא **ESP32-S3** מתוצרת **Espressif**, החברה שמאחורי לוחות ה-ESP. כך אנחנו מקבלים גם את דרך העבודה הקלה של Arduino *וגם* את העוצמה האלחוטית של ה-ESP32.

![ה-Arduino Nano ESP32 במבט מלמעלה: מחבר ה-USB-C, נורית ה-LED L, נורית ההפעלה, לחצן האיפוס, נורית ה-RGB, מודול ה-ESP32-S3 עם האנטנה שלו ושתי שורות הפינים](assets/nano-esp32/board.svg)

## הלוח במספרים

| | Nano ESP32 | להשוואה: Arduino Uno |
|--|------------|-----------------------------|
| **שבב** | ESP32-S3, 2 ליבות | ATmega328P, ליבה אחת |
| **מהירות** | עד 240 MHz | 16 MHz |
| **זיכרון (RAM)** | 512 KB | 2 KB |
| **מקום לתוכנית שלכם (flash)** | 16 MB | 32 KB |
| **אלחוטי** | Wi‑Fi ו-Bluetooth | אין |
| **מתח הפינים** | **3.3 V** | 5 V |
| **גודל** | 45 × 18 mm | 69 × 53 mm |

אל תדאגו לגבי זכירת המספרים האלה. הנקודה היא שהלוח הזעיר הזה חזק פי כמה וכמה מה-Arduino Uno הקלאסי, והוא יכול לדבר עם האינטרנט.

## החלקים של הלוח

| חלק | מה הוא עושה |
|------|--------------|
| **מחבר USB-C** | מספק מתח ללוח ומחבר אותו למחשב שלכם. התוכניות שלכם נטענות דרכו, והלוח יכול לשלוח הודעות בחזרה דרך אותו כבל |
| **מודול ESP32-S3** | המוח: המיקרו-בקר, הזיכרון שלו והרדיו, הכול מתחת למכסה מתכת אחד |
| **אנטנה** | חלק מהמודול. היא שולחת וקולטת את אותות ה-Wi‑Fi וה-Bluetooth, אז אל תכסו אותה במתכת או ביד |
| **נורית הפעלה** (Power LED) | נדלקת בירוק כשיש ללוח מתח |
| **נורית "L"** | נורית LED קטנה שמחוברת לפין **D13**. התוכנית הראשונה שלכם תגרום לה להבהב |
| **נורית RGB** | נורית אדומה, ירוקה וכחולה באחת. ערבבו אותן מהקוד שלכם כדי ליצור כל צבע |
| **לחצן איפוס** (Reset) | מתחיל את התוכנית שלכם מחדש, כמו לכבות ולהדליק את הלוח |
| **שורות פינים** (pin headers) | שתי שורות של 15 פינים. לכאן מחברים נוריות LED, לחצנים, חיישנים ומנועים |

## הפינים

הפינים הם הדרך שבה הלוח מדבר עם העולם. לכל אחד יש שם, שמודפס על הלוח לידו:

![30 הפינים של ה-Nano ESP32: פינים דיגיטליים D0 עד D13, כניסות אנלוגיות A0 עד A7, פיני מתח 3V3, VBUS ו-VIN, שני פיני GND, RST, והפינים המיוחדים B0 ו-B1](assets/nano-esp32/pinout.svg)

| קבוצה | פינים | משמשים ל |
|-------|------|----------|
| **דיגיטליים** | D0 – D13 | הדלקה וכיבוי של דברים (נוריות LED, מנועים דרך דרייבר) וקריאת לחצנים. D0 ו-D1 גם מעבירים מידע טורי (serial) |
| **אנלוגיים** | A0 – A7 | קריאת מתח, כמו המיקום של כפתור סיבובי או רמת האור בחיישן אור |
| **מתח** | 3V3, VBUS, VIN | **3V3** מוציא 3.3 V למעגלים שלכם. **VBUS** נותן את ה-5 V שמגיעים מכבל ה-USB. **VIN** הוא כניסה לסוללה או לספק של 6–21 V כשאין USB |
| **אדמה** | GND (שני פינים) | נקודת הייחוס של 0 V. כל מעגל שתבנו מתחבר ל-GND |
| **מיוחדים** | RST, B0, B1 | פיני איפוס ואתחול (boot). השאירו אותם לא מחוברים |

> **ה-Nano ESP32 עובד על 3.3 V.** פין מוציא 3.3 V כשהוא דולק, ואסור שהוא יקבל אף פעם יותר מ-3.3 V. חיבור של אות 5 V לפין יכול להרוס את הלוח.

נלמד איך להשתמש בכל קבוצת פינים בפריטים הבאים.

## תכנות הלוח ב-C

את ה-Nano ESP32 מתכנתים ב-**C** (ה"שפה" של Arduino היא C ו-C++ עם כמה פונקציות מוכנות) בעזרת **Arduino IDE** החינמי. IDE (Integrated Development Environment, סביבת פיתוח משולבת) היא התוכנה שבה כותבים את הקוד, בודקים אותו ושולחים אותו ללוח.

![ה-Arduino IDE על מחשב נייד עם תוכנית הבהוב; התוכנית המקומפלת עוברת בכבל ה-USB-C אל ה-Nano ESP32, ונורית ה-L שלו מהבהבת](assets/nano-esp32/upload.svg)

1. כותבים תוכנית, שנקראת **סקיצה** (sketch), ב-Arduino IDE.
2. לוחצים על **Upload**. ה-IDE **מקמפל** (compiles) את קוד ה-C שלכם לקוד מכונה שה-ESP32-S3 מבין, ושולח אותו בכבל ה-USB.
3. הלוח מתחיל להריץ את התוכנית שלכם מיד, ומריץ אותה שוב בכל פעם שהוא מקבל מתח.

לכל סקיצה יש שני חלקים: `setup()` רץ פעם אחת כשהלוח עולה, ו-`loop()` רץ שוב ושוב, לנצח. הנה התוכנית הראשונה הקלאסית. היא מהבהבת את נורית ה-"L":

```c
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);     // LED_BUILTIN is the LED "L" on D13
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);  // LED on
  delay(500);                       // wait half a second
  digitalWrite(LED_BUILTIN, LOW);   // LED off
  delay(500);
}
```

אתם לא צריכים להבין כל שורה כבר עכשיו. נתקין את ה-IDE יחד ונעבור על התוכנית הזו צעד אחר צעד בפריטים הבאים.
