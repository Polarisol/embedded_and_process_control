# LDR (נגד תלוי אור)

**מה זה:** דיסקית קטנה עם קו מפותל למעלה. זה נגד שההתנגדות שלו **יורדת כשאור מאיר עליו**: בערך 1 kΩ באור חזק, ומאות kΩ בחושך.

**משמש ל:** פנסי רחוב שנדלקים בשקיעה, מנורות לילה, בהירות מסך אוטומטית בטלפון (טלפונים משתמשים בחיישן אור מדויק יותר, אבל הרעיון זהה) ואזעקות "האם הקופסה נפתחה?".

**איך הוא מדבר:** **אנלוגי**. הלוח לא יכול למדוד התנגדות ישירות, רק מתח. לכן מצמידים ל-LDR נגד קבוע ובונים מחלק מתח, בדיוק כמו בפוטנציומטר. כאן האור, ולא היד שלכם, מזיז את ה"מגב".

![LDR למעלה ונגד 10 kΩ למטה יוצרים מחלק מתח שנכנס ל-A0](assets/sensors/ldr.svg)

```c
const int LED_PIN = 13;
const int DARK_LEVEL = 300;    // adjust this for your room

void setup() {
  Serial.begin(9600);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int light = analogRead(A0);
  Serial.println(light);

  if (light < DARK_LEVEL) {
    digitalWrite(LED_PIN, HIGH);   // it's dark: night light ON
  } else {
    digitalWrite(LED_PIN, LOW);
  }
  delay(200);
}
```

החליפו בין ה-LDR לנגד ה-10 kΩ והקריאות יתהפכו: אור חזק ייתן אז מספר *נמוך*. אף אחת מהדרכים לא שגויה, רק תזכרו איזו מהן בניתם.

## אתגר

**הבהוב שנשלט באור:** השתמשו ב-LDR כדי לקבוע כמה מהר נורית LED מהבהבת. ככל שהחדר חשוך יותר, היא מהבהבת מהר יותר.
