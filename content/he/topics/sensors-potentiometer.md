# פוטנציומטר

**מה זה:** נגד עם רגל שלישית, ה**מגב** (wiper), שמחליקה לאורכו כשמסובבים את הכפתור. יש לו שלוש רגליים: שני הקצוות והמגב באמצע.

**משמש ל:** כפתורי ווליום, מעמעמי תאורה, כפתור המהירות במאוורר, וג'ויסטיקים (ג'ויסטיק הוא פשוט שני פוטנציומטרים, אחד לימין-שמאל ואחד למעלה-למטה).

**איך הוא מדבר:** **אנלוגי**. מחברים קצה אחד לאספקה, את הקצה השני ל-GND, ואת המגב לפין אנלוגי. סיבוב הכפתור מזיז את המגב מ-0 V ועד מתח האספקה. המעגל הזה נקרא **מחלק מתח** (voltage divider), ותפגשו אותו שוב ושוב.

![פוטנציומטר מחובר כמחלק מתח, כשהמגב מחובר ל-A0](assets/sensors/potentiometer.svg)

```c
void setup() {
  Serial.begin(9600);
}

void loop() {
  int value = analogRead(A0);              // 0 to 1023 on an Uno
  float volts = value * 5.0 / 1023.0;      // convert back to volts
  Serial.print(value);
  Serial.print("  ->  ");
  Serial.print(volts);
  Serial.println(" V");
  delay(200);
}
```

ב-ESP32 השתמשו בפין שתומך בקריאה אנלוגית, כמו GPIO 34 (`analogRead(34)`), ושנו את החישוב ל-`value * 3.3 / 4095.0`.

**נסו את זה:** פתחו את **Tools → Serial Plotter** ב-Arduino IDE וסובבו את הכפתור. תקבלו גרף חי של תנועת היד שלכם.
