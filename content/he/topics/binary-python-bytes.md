# בתים ומחרוזות בפייתון

ב-**ASCII ו-Unicode** ראינו שטקסט נשמר כמספרים. פייתון מאפשרת לראות את זה ישירות, כי יש בה שני טיפוסים שונים:

- `str`: **טקסט**, רצף של תווים, כמו `"Hello"`.
- `bytes`: **בתים גולמיים**, רצף של מספרים בין **0 ל-255**, כמו `b'Hello'`.

המעבר מטקסט לבתים נקרא **קידוד** (encoding), והמעבר חזרה נקרא **פענוח** (decoding).

## יצירת בתים ממספרים

נותנים ל-`bytes()` רשימה של מספרים, ומקבלים בית אחד לכל מספר:

```python
b = bytes([65, 66, 67])
b             # b'ABC'
```

למה פייתון מציגה `b'ABC'` ולא את המספרים? ה-`b` בהתחלה אומר "אלה בתים, לא טקסט". כדי שיהיה קל לקרוא בתים, פייתון מציגה כל בית שהוא תו ASCII שאפשר להדפיס כתו עצמו. הסתכלו ב**טבלת ASCII**: 65 הוא `A`, 66 הוא `B` ו-67 הוא `C`. בפנים, `b` הוא עדיין רק שלושה מספרים.

בית שהוא לא תו שאפשר להדפיס מוצג ב-hex, עם `\x` לפניו (ראו **הקסדצימלי**):

```python
bytes([1, 2, 72, 10])    # b'\x01\x02H\n'
```

כאן 1 ו-2 מוצגים כ-`\x01` ו-`\x02`, ‏72 הוא `H`, ו-10 הוא תו השורה החדשה `\n`.

בית יכול להחזיק רק 0 עד 255, ולכן `bytes([300])` נותן שגיאה: `ValueError: bytes must be in range(0, 256)`.

## מבתים לטקסט: `decode()`

`decode()` קורא את הבתים כתווים, לפי קידוד, ומחזיר `str`:

```python
b.decode('utf-8')    # 'ABC'
```

שימו לב לפלט: `'ABC'` בלי `b` לפניו. עכשיו זה טקסט.

## מטקסט לבתים: `encode()`

`encode()` עושה את הכיוון ההפוך. הוא הופך כל תו לבתים שלו:

```python
string = "Hello, World!"
bytes_rep = string.encode('utf-8')
bytes_rep            # b'Hello, World!'
```

זה נראה כמעט כמו הטקסט, אבל ה-`b` אומר לכם שעכשיו אלה 13 בתים, מוכנים להישלח בפורט טורי, ברשת או להישמר בקובץ. כל אלה שולחים רק בתים, אף פעם לא "טקסט".

## לראות את המספר של כל בית: `list()`

כדי לראות את המספרים עצמם, הופכים את הבתים לרשימה:

```python
print(list(bytes_rep))
# [72, 101, 108, 108, 111, 44, 32, 87, 111, 114, 108, 100, 33]
```

בדקו אותם מול טבלת ASCII: ‏72 הוא `H`, ‏101 הוא `e`, ‏108 הוא `l` (פעמיים), 44 הוא הפסיק, 32 הוא הרווח ו-33 הוא `!`.

אפשר גם לקחת בית אחד בעזרת אינדקס. בית בודד הוא פשוט `int`:

```python
bytes_rep[0]         # 72
```

ו-`decode()` מחזיר את הטקסט:

```python
result = bytes_rep.decode('utf-8')
print(result)        # Hello, World!
```

## לא כל תו הוא בית אחד

בטקסט באנגלית כל תו הוא בית אחד, כי UTF-8 משתמש בשבילו בבית ה-ASCII הרגיל. בעברית זה שונה. כמו שראינו ב-**ASCII ו-Unicode**, אות עברית תופסת **2 בתים** ב-UTF-8:

```python
word = "שלום"
len(word)                     # 4 characters
data = word.encode('utf-8')
len(data)                     # 8 bytes
list(data)                    # [215, 169, 215, 156, 215, 149, 215, 157]
```

בגלל זה אי אפשר סתם לחתוך בתים באמצע. אם הגיע רק הבית הראשון, `bytes([215]).decode('utf-8')` נותן `UnicodeDecodeError`, כי חצי אות היא לא אות.

## סיכום

| יש לכם | אתם רוצים | משתמשים ב- |
|----------|----------|-----|
| רשימה של מספרים | בתים | `bytes([72, 105])` |
| בתים | טקסט | `b.decode('utf-8')` |
| טקסט | בתים | `s.encode('utf-8')` |
| בתים | המספרים | `list(b)` או `b[0]` |
| בתים | hex | `b.hex(' ')` |
