# יסודות שפת C

אתם כבר יודעים Python, אז אתם כבר יודעים לתכנת. C משתמשת באותם רעיונות (משתנים, `if`, לולאות, פונקציות) עם דרך כתיבה קפדנית יותר. העמוד הזה מציג את היסודות לצד מה שאתם כבר מכירים.

> **שלושת ההבדלים הגדולים מ-Python**
> 1. כל פקודה מסתיימת ב**נקודה-פסיק** `;`
> 2. בלוקים מסומנים ב**סוגריים מסולסלים** `{ }`, ולא בהזחה. תזיחו בכל זאת, כדי שאנשים יוכלו לקרוא את הקוד שלכם.
> 3. לכל משתנה יש **טיפוס** (type) שאתם מצהירים עליו, והוא אף פעם לא משתנה.

C היא גם שפה **מהודרת** (compiled): לפני שהתוכנית יכולה לרוץ, מהדר (compiler) מתרגם את כל הקובץ לקוד מכונה. טעויות כמו `;` חסר מדווחות כבר אז, לפני שמשהו רץ.

## המבנה ההכרחי של תוכנית

לכל תוכנית C יש פונקציה בשם `main`. התוכנית מתחילה שם.

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, world!\n");
    return 0;
}
```

| שורה | מה היא עושה |
|------|--------------|
| `#include <stdio.h>` | כמו `import` ב-Python. `stdio.h` נותן לכם את `printf` ואת `scanf` |
| `int main(void)` | הפונקציה `main`. היא לא מקבלת כלום (`void`) ומחזירה `int` |
| `{ ... }` | כל מה שבין הסוגריים המסולסלים שייך ל-`main` |
| `printf(...)` | מדפיסה טקסט. בניגוד ל-`print` של Python, היא **לא** מוסיפה ירידת שורה, אז כותבים `\n` בעצמכם |
| `return 0;` | מסיימת את התוכנית. `0` אומר "הכול עבר בסדר" |

הערות כותבים עם `//` לשורה אחת, או עם `/* ... */` לכמה שורות. ה-`#` של Python הוא לא הערה ב-C.

## הצהרה על משתנים

ב-Python כותבים `age = 20`. ב-C אומרים קודם את הטיפוס:

```c
int age = 20;           // whole number
float temperature = 36.6;  // number with a decimal point
double pi = 3.14159265358979;  // decimal number with more precision
char grade = 'A';       // one single character, in single quotes
int counter;            // declared now, given a value later
counter = 0;
```

| טיפוס | מכיל | קוד ב-`printf` / `scanf` |
|------|-------|-------------------------|
| `int` | מספרים שלמים | `%d` |
| `float` | מספרים עשרוניים, בערך 7 ספרות משמעותיות | `%f` |
| `double` | מספרים עשרוניים, בערך 15 ספרות משמעותיות | `%f` ב-`printf`, `%lf` ב-`scanf` |
| `char` | תו אחד | `%c` |
| מחרוזת | טקסט (ראו בהמשך) | `%s` |

ה-`float` של Python הוא בעצם ה-`double` של C. `float` תופס חצי זיכרון (4 בתים, לא 8), וזה חשוב במיקרו-בקר קטן, אבל הוא פחות מדויק.

כדי להדפיס משתנה, שימו את הקוד שלו בטקסט ואת המשתנה אחריו:

```c
printf("Age: %d, temperature: %.1f, grade: %c\n", age, temperature, grade);
```

`%.1f` אומר "ספרה אחת אחרי הנקודה העשרונית". אין f-strings ב-C.

> **זהירות:** משתנה בלי ערך התחלתי מכיל **זבל**, לא אפס. תמיד תנו לו ערך לפני שאתם משתמשים בו.

## אופרטורים מתמטיים

`+`, `-`, `*`, `/` ו-`%` (שארית) עובדים כמו ב-Python, עם כמה הפתעות:

| Python | C | הערה |
|--------|---|------|
| `7 / 2` נותן `3.5` | `7 / 2` נותן `3` | חילוק של שני `int`-ים זורק את השבר. כתבו `7.0 / 2` כדי לקבל `3.5` |
| `7 // 2` | `7 / 2` | אין אופרטור `//`. ב-C, `//` פותח הערה |
| `2 ** 3` | `pow(2, 3)` | אין `**`. `pow` צריך `#include <math.h>` |
| `x += 1` | `x++;` | `x++` מוסיף אחד ו-`x--` מחסיר אחד. גם `x += 1` עובד |
| `and`, `or`, `not` | `&&`, `\|\|`, `!` | האופרטורים הלוגיים הם סימנים |
| `True`, `False` | `1`, `0` | אפס זה שקר, כל דבר אחר זה אמת |

ההשוואות `==`, `!=`, `<`, `>`, `<=`, `>=` זהות לאלה של Python.

## מערכים

מערך (array) הוא כמו רשימה ב-Python, אבל קפדני יותר: **לכל הפריטים אותו טיפוס** ו**הגודל קבוע** מרגע שיוצרים אותו.

כדי להצהיר על מערך, כותבים את הטיפוס, שם ואת הגודל בסוגריים מרובעים:

```c
int scores[5];      // room for 5 ints: scores[0] to scores[4]
```

מכניסים ערכים וקוראים אותם בחזרה עם אינדקס, שמתחיל ב-0 כמו ב-Python:

```c
scores[0] = 90;
scores[1] = 75;
scores[4] = 100;

printf("%d\n", scores[1]);            // prints 75
int total = scores[0] + scores[4];    // 190
```

> **זהירות:** הצהרה על מערך לא מנקה אותו. ל-`scores[2]` ול-`scores[3]` אף פעם לא ניתן ערך, ולכן הם מכילים **זבל**: מה שבמקרה היה בזיכרון הזה.

כדי להימנע מזבל, אפשר לתת את הערכים ההתחלתיים בסוגריים מסולסלים כשמצהירים על המערך:

```c
int scores[5] = {90, 75, 82, 60, 100};
```

לא חייבים לרשום את כולם. אם נותנים פחות ערכים מהגודל, השאר מקבלים **אפס**:

```c
int scores[5] = {90, 75};     // 90, 75, 0, 0, 0
```

זו דרך מהירה להתחיל עם מערך מלא באפסים:

```c
int scores[5] = {0};          // 0, 0, 0, 0, 0
```

הסוגריים המסולסלים עובדים רק בהצהרה. אחרי זה משנים את הפריטים אחד אחד.

דברים שאי אפשר לעשות ב-C:

- אין `append`: המערך לא יכול לגדול או לקטון
- אין `len()`: אתם צריכים לזכור את הגודל בעצמכם
- אין אינדקסים שליליים: `scores[-1]` הוא שגיאה בלוגיקה שלכם
- אין `print(scores)`: מדפיסים את הפריטים אחד אחד בלולאה

> **זהירות:** C לא בודקת את האינדקסים שלכם. `scores[7]` לא יזרוק שגיאה. הוא בשקט יקרא או יהרוס זיכרון אחר כלשהו. להישאר בתוך המערך זה התפקיד שלכם.

## מחרוזות

ב-C אין טיפוס מחרוזת. מחרוזת היא **מערך של `char`**, שנכתב ב**מירכאות כפולות**:

```c
char name[20] = "Dana";
printf("Hello, %s!\n", name);
```

C מסמנת את סוף הטקסט בתו נסתר `'\0'`, ולכן `"Dana"` צריכה 5 מקומות. תמיד תנו למערך גודל גדול לפחות באחד מהטקסט הארוך ביותר שאתם מצפים לו.

מירכאות בודדות וכפולות **לא** מתחלפות זו בזו כמו ב-Python: `'A'` הוא `char` אחד, `"A"` היא מחרוזת.

### שינוי מחרוזת בהמשך

הצורה `= "..."` עובדת **רק בהצהרה**. ברגע שהמחרוזת קיימת, אי אפשר לתת לה טקסט חדש עם `=`:

```c
char name[20] = "Dana";    // fine: this is the declaration

name = "Noa";              // ERROR: the compiler refuses this
```

כדי לשנות את הטקסט, משתמשים בפונקציה. הן נמצאות ב-`string.h`, אז הוסיפו `#include <string.h>` בראש הקובץ. `strcpy` ("string copy") מעתיקה טקסט חדש לתוך המחרוזת:

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char name[20] = "Dana";
    printf("%s\n", name);       // Dana

    strcpy(name, "Noa");        // name now holds "Noa"
    printf("%s\n", name);       // Noa

    strcat(name, " Levi");      // add text to the end
    printf("%s\n", name);       // Noa Levi

    return 0;
}
```

היעד בא ראשון: `strcpy(name, "Noa")` נקרא כמו `name = "Noa"`. ודאו שהטקסט החדש נכנס במערך, כי `strcpy` ו-`strcat` לא בודקות.

אותו דבר נכון לגבי שאר האופרטורים של מחרוזות ב-Python. לכל אחד יש פונקציה:

| Python | C |
|--------|---|
| `len(name)` | `strlen(name)` |
| `name = "Noa"` | `strcpy(name, "Noa");` |
| `if name == "Noa":` | `if (strcmp(name, "Noa") == 0)` |
| `a + b` | `strcat(a, b);` |

## קריאת קלט עם `scanf`

`scanf` היא הגרסה של C ל-`input()`. היא משתמשת באותם קודים כמו `printf`, והיא ממירה את הטקסט לטיפוס הנכון בשבילכם.

```c
int age;
float height;
char name[20];

printf("Enter your age: ");
scanf("%d", &age);

printf("Enter your height: ");
scanf("%f", &height);

printf("Enter your name: ");
scanf("%19s", name);
```

> **כלל אצבע:** שימו `&` לפני **משתנים פשוטים** (`int`, `float`, `char`), ו**בלי** `&` לפני **מערכים** (כולל מחרוזות).

לשכוח את ה-`&` זו הטעות הנפוצה ביותר עם `scanf`, ובדרך כלל היא מקריסה את התוכנית.

עוד שני דברים שכדאי לדעת: `%s` קורא **מילה אחת** ועוצר ברווח, וה-`19` ב-`%19s` מונע מהמשתמש להקליד יותר ממה ש-`name[20]` יכול להכיל.

## משפטי `if`

התנאי נכתב ב**סוגריים עגולים** והבלוק ב**סוגריים מסולסלים**. את `elif` כותבים `else if`.

```c
if (temperature > 38.0) {
    printf("Fever\n");
} else if (temperature < 35.0) {
    printf("Too cold\n");
} else {
    printf("Normal\n");
}
```

### שילוב תנאים

המילים `and`, `or` ו-`not` של Python נכתבות ב-C כסימנים:

| Python | C | אמת כאשר |
|--------|---|-----------|
| `a and b` | `a && b` | **שניהם** אמת |
| `a or b` | `a \|\| b` | **לפחות אחד** אמת |
| `not a` | `!a` | `a` שקר |
| `a != b` | `a != b` | `a` ו-`b` שונים (כמו ב-Python) |

```c
int age = 20;
int has_ticket = 1;      // 1 = true, 0 = false
char grade = 'B';

// && : both must be true
if (age >= 18 && has_ticket) {
    printf("You may enter\n");
}

// || : one is enough
if (grade == 'A' || grade == 'B') {
    printf("Well done\n");
}

// != : not equal
if (grade != 'F') {
    printf("You passed\n");
}

// ! : flips true and false
if (!has_ticket) {
    printf("Please buy a ticket\n");
}
```

כשמערבבים אותם, השתמשו בסוגריים נוספים כדי שהסדר יהיה ברור:

```c
if ((age < 6 || age > 65) && !has_ticket) {
    printf("You get a free ticket\n");
}
```

ב-Python אפשר לכתוב `0 < x < 10`. ב-C חייבים לפצל את זה לשתי השוואות: `x > 0 && x < 10`.

> **זהירות:** `=` משים ערך ו-`==` משווה. `if (x = 5)` הוא C חוקי, אבל הוא שם 5 ב-`x` ותמיד אמת.
>
> באותו אופן, כתבו `&&` ו-`||` עם **שני** סימנים. `&` או `|` בודד הוא אופרטור אחר שעובד על ביטים.

## לולאות

לולאת `while` זהה לזו של Python, עם סוגריים עגולים ומסולסלים:

```c
int count = 3;
while (count > 0) {
    printf("%d\n", count);
    count--;
}
```

לולאת `for` נראית אחרת. יש לה שלושה חלקים, מופרדים בנקודה-פסיק: **התחלה; להמשיך כל עוד; צעד**.

```c
for (int i = 0; i < 5; i++) {
    printf("%d\n", i);
}
```

זה ה-`for i in range(5):` של Python, והיא מדפיסה 0 עד 4. אין `for item in list`. כדי לעבור על מערך, עוברים בלולאה על האינדקסים שלו:

```c
for (int i = 0; i < 5; i++) {
    printf("%d\n", scores[i]);
}
```

`break` ו-`continue` עובדים כמו ב-Python.

## משפט `switch`

`switch` מחליף שרשרת ארוכה של `if` / `else if` שמשווה משתנה אחד לכמה ערכים קבועים.

```c
switch (grade) {
    case 'A':
        printf("Excellent\n");
        break;
    case 'B':
        printf("Good\n");
        break;
    default:
        printf("Keep practicing\n");
        break;
}
```

- `default` רץ כששום case לא מתאים, כמו `else` אחרון
- זה עובד רק עם ערכי `int` ו-`char`, לא עם מחרוזות או `float`

> **זהירות:** כל case צריך `break`. בלעדיו, התוכנית ממשיכה לרוץ לתוך ה-case הבא.

> **זהירות:** לעולם אל תצהירו על משתנים בתוך case, או בכל מקום בתוך ה-`switch`. זה גורם לשגיאות קומפילציה מבלבלות, ואפשר לדלג על המשתנה כך שיישאר עם זבל. הצהירו על מה שאתם צריכים **מעל** ה-`switch` ורק השתמשו בו בפנים:
>
> ```c
> int bonus = 0;          // declared before the switch
>
> switch (grade) {
>     case 'A':
>         bonus = 10;     // only used here
>         break;
>     case 'B':
>         bonus = 5;
>         break;
> }
> ```

## פונקציות

במקום `def`, כותבים את **הטיפוס שהפונקציה מחזירה**, וגם כל פרמטר מקבל טיפוס.

```c
#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

void greet(void)
{
    printf("Welcome!\n");
}

int main(void)
{
    greet();
    int sum = add(3, 4);
    printf("Sum: %d\n", sum);
    return 0;
}
```

- `void` כטיפוס ההחזרה אומר שהפונקציה לא מחזירה כלום
- `void` בתוך הסוגריים אומר שהיא לא מקבלת פרמטרים
- קריאה לפונקציה נראית בדיוק כמו ב-Python: `add(3, 4)`

> **זהירות:** המהדר קורא את הקובץ מלמעלה למטה, ולכן פונקציה חייבת להופיע **מעל** המקום שבו קוראים לה. בגלל זה `main` נמצאת בתחתית.
