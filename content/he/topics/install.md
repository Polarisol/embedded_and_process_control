# הוראות התקנה

1. התקינו את uv: הפעילו את האפליקציה "Powershell" של Windows וכתבו:

   ```powershell
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```

   אפשרויות אחרות (למשל ל-Mac) אפשר לראות כאן: <https://docs.astral.sh/uv/getting-started/installation/>

2. GitHub:
   1. צרו חשבון GitHub חינמי כאן: <https://github.com/signup>
   2. (אפשר גם אחר כך) קבלו את חבילת הסטודנטים המלאה מכאן: [GitHub Education](https://education.github.com/pack)

3. VS Code:
   1. הורידו את VS Code מכאן: <https://code.visualstudio.com/>
   2. התקינו אותו - **אבל הקפידו לסמן את שתי תיבות הסימון של "Add Open with Code"**
   3. הפעילו את VS Code, והוא יבקש מכם להתחבר ל-GitHub (עם החשבון שיצרתם בשלב 2)
   4. עברו ללשונית ה-Extensions והתקינו את התוספים "python" ו-"jupyter" של Microsoft (תוספים נוספים יותקנו אוטומטית, וזה בסדר)

4. Git:
   התקינו מכאן: <https://git-scm.com/install/>

5. DBBrowser:
   הורידו והתקינו מכאן (הגרסה הרגילה, 64bit): <https://sqlitebrowser.org/dl/>

6. אופציונלי:
   1. notepad++ מכאן (הקישור העליון): <https://notepad-plus-plus.org/downloads/>
   2. paint.net מכאן (הקישור הכחול בצד): <https://www.dotpdn.com/downloads/pdn.html>
