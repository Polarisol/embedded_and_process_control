# גלים

פין דיגיטלי יכול להיות רק **HIGH ‏(3.3 V)** או **LOW ‏(0 V)**. אבל אם מדליקים ומכבים אותו שוב ושוב, מקבלים **גל ריבועי** (square wave). כשבוחרים כמה מהר הגל חוזר על עצמו וכמה זמן הוא נשאר גבוה, אותו פין יכול לעמעם נורית LED, לקבוע את המהירות של מנוע, לנגן מנגינה על זמזם ולהזיז סרוו לזווית מדויקת.

הפריט הזה מראה את שלוש הדרכים שבהן משתמשים בגלים ריבועיים. הוא נבנה על הפריט [הפינים הדיגיטליים של Nano ESP32](topic.html?id=microcontrollers), אז קראו אותו קודם.

## לגל ריבועי יש שלושה מספרים

![גל ריבועי אחד שהחלקים שלו מסומנים: זמן הגובה (high time), זמן הנמוך (low time) והמחזור T של סיבוב שלם אחד; ומתחתיו שלושה כרטיסים: המחזור T = 1 ms, התדר f = 1 / T = 1000 Hz, ומחזור העבודה 0.25 ms / 1 ms = 25 %](assets/waves/square-wave.svg)

| מספר | מה הוא | דוגמה |
|--------|-----------|---------|
| **מחזור** (period) ‏`T` | הזמן של סיבוב שלם אחד: חלק גבוה אחד וחלק נמוך אחד | 1 ms |
| **תדר** (frequency) ‏`f` | כמה סיבובים קורים בכל שנייה. ‏`f = 1 / T`, ונמדד ב**הרץ (Hz)** | 1 / 1 ms = 1000 Hz |
| **מחזור עבודה** (duty cycle) | החלק מהמחזור שבו הפין גבוה. ‏`duty = high time / T` | 0.25 ms / 1 ms = 25 % |

מחזור ותדר הם שתי דרכים להגיד את אותו הדבר: מחזור קצר יותר אומר תדר גבוה יותר. אז בעצם יש רק שני דברים שאפשר לשנות: **כמה ארוך הסיבוב**, ו**כמה ממנו גבוה**. כל סוג של רכיב מקשיב לדבר אחר:

| | ‏PWM (נורית, מנוע) | זמזם | סרוו |
|---|---|---|---|
| **מחזור** | נשאר קבוע (בערך 1 ms) | **משתנה** | נשאר קבוע (20 ms) |
| **זמן הגובה** | **משתנה** | תמיד חצי מהמחזור | **משתנה** (0.5 – 2.4 ms) |
| **מחזור עבודה** | 0 – 100 % | תמיד 50 % | רק 2.5 – 12 % |
| **מה הרכיב מרגיש** | את **ההספק הממוצע** | את **התדר**, בתור צליל | את **רוחב** הפולס, בתור זווית |
| **ב-Arduino** | `analogWrite()` | `tone()` | ספריית סרוו, או ביד |

## לבנות כל גל ביד

לפני שנשתמש בפונקציות המובנות, הנה פונקציה קטנה אחת שיוצרת **סיבוב אחד** של כל גל ריבועי:

```c
// One cycle of a square wave: HIGH for highUs microseconds, then LOW for lowUs.
void squareWave(int pin, long highUs, long lowUs) {
  digitalWrite(pin, HIGH);
  delayMicroseconds(highUs);
  digitalWrite(pin, LOW);
  delayMicroseconds(lowUs);
}
```

קראו לה שוב ושוב ב-`loop()`, והפין יוצר גל. שלושת השימושים שבהמשך הם פשוט שלוש דרכים שונות לבחור את `highUs` ואת `lowUs`.

## ‏1. PWM: מחזור קבוע, מחזור עבודה משתנה

כדי לתת לנורית או למנוע **חלק** מההספק שלהם, משאירים את המחזור קבוע ומשנים כמה ממנו גבוה. זה **PWM** ‏(Pulse Width Modulation, אפנון רוחב פולס):

![שלושה אותות PWM עם אותו מחזור: ב-10 % מחזור עבודה הממוצע הוא 0.33 V והנורית עמומה, ב-50 % הממוצע 1.65 V והיא בחצי עוצמה, ב-90 % הממוצע 2.97 V והיא בהירה](assets/waves/pwm-average.svg)

כשהפין גבוה, העומס מקבל **הספק מלא**. כשהוא נמוך, הוא לא מקבל **כלום**. העומס איטי מכדי לעקוב אחרי כל פולס (נורית LED היא מהירה, אבל העין שלכם לא, ולמנוע יש משקל שממשיך לסובב אותו), ולכן מה שקובע הוא **הממוצע**:

**הספק ממוצע = מחזור עבודה × הספק מלא**

ב-50 % מחזור עבודה המנוע מקבל חצי מההספק שלו, והמתח הממוצע הוא חצי מ-3.3 V. כאן רק מחזור העבודה חשוב. המחזור רק צריך להיות **קצר מספיק** כדי שהעומס לא יוכל לעקוב אחרי הפולסים הבודדים.

ביד, עם מחזור של 1000 µs ‏(1 ms, כלומר 1000 Hz):

```c
const int LED_PIN = D2;
const long PERIOD_US = 1000;     // 1 ms: stays the same

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int duty = 25;                               // percent: change this
  long highUs = PERIOD_US * duty / 100;
  squareWave(LED_PIN, highUs, PERIOD_US - highUs);
}
```

בתוכניות אמיתיות, תנו לחומרת ה-PWM של הלוח לעשות את זה ברקע עם `analogWrite(pin, value)`, כש-`value` נע בין 0 ‏(0 %) ל-255 ‏(100 %). הפריט על [הפינים הדיגיטליים](topic.html?id=microcontrollers) מראה איך מעמעמים איתו נורית.

**נסו בעצמכם:** שנו את `PERIOD_US` ל-`100000` ‏(0.1 שניות). עכשיו המחזור ארוך מדי בשביל העין שלכם, והנורית מהבהבת במקום לזהור חלש.

> פין נותן רק בערך 20 mA, מספיק לנורית LED אבל לא למנוע. כדי לשלוט במהירות של מנוע עם PWM, הפין מפעיל **MOSFET** שמפעיל את המנוע. ראו את יחידת [המנועים](topic.html?id=motors).

## ‏2. זמזם: מחזור עבודה קבוע של 50 %, תדר משתנה

**זמזם פסיבי** (passive buzzer) הוא דיסק קטן שזז קצת בכל פעם שהמתח עליו משתנה. כל דחיפה ומשיכה מזיזה את האוויר, ורצף מהיר שלהן הוא **צליל**. כאן הממוצע לא משנה בכלל. מה שאתם שומעים הוא **התדר**: יותר סיבובים בשנייה נשמעים כמו צליל גבוה יותר.

![שלושה גלים, כולם גבוהים בחצי מהמחזור ונמוכים בחצי השני: 262 Hz (התו C4, ‏T = 3.82 ms) הוא צליל נמוך, 440 Hz ‏(A4, ‏2.27 ms) באמצע, 880 Hz ‏(A5, ‏1.14 ms) גבוה](assets/waves/buzzer-frequency.svg)

מחזור העבודה נשאר **50 %**: גבוה בחצי מהמחזור ונמוך בחצי השני. כך הזמזם מקבל דחיפות ומשיכות שוות, וזה נותן את הצליל הכי חזק ונקי. בני אדם שומעים מבערך 20 Hz ועד 20,000 Hz, וזמזמים קטנים נשמעים הכי טוב בין בערך 500 Hz ל-4000 Hz.

**חיבור:** חברו את הרגל **+** של הזמזם ל-**D5** דרך נגד של **100 Ω**, ואת הרגל השנייה ל-**GND**.

ביד: לתדר `f`, המחזור הוא `1,000,000 / f` מיקרו-שניות, אז כל חצי הוא `500,000 / f`:

```c
const int BUZZER_PIN = D5;

// Play a note for some milliseconds, by hand.
void playNote(long freq, long ms) {
  long halfUs = 500000 / freq;               // half of the period
  long cycles = freq * ms / 1000;
  for (long i = 0; i < cycles; i++) {
    squareWave(BUZZER_PIN, halfUs, halfUs);  // 50 % duty
  }
}

void setup() {
  pinMode(BUZZER_PIN, OUTPUT);
}

void loop() {
  playNote(262, 300);   // C
  playNote(330, 300);   // E
  playNote(392, 300);   // G
  playNote(523, 600);   // high C
  delay(1000);
}
```

ל-Arduino יש פונקציה מובנית שיוצרת את הגל הזה ברקע: `tone(pin, frequency)` מתחילה אותו, `noTone(pin)` עוצרת אותו, ו-`tone(pin, frequency, ms)` מנגנת לזמן קבוע. הנה מנגינה איתה:

```c
const int BUZZER_PIN = D5;

int notes[]     = {262, 294, 330, 349, 392, 440, 494, 523};  // C D E F G A B C
int durations[] = {300, 300, 300, 300, 300, 300, 300, 600};  // ms

void setup() {
  for (int i = 0; i < 8; i++) {
    tone(BUZZER_PIN, notes[i]);
    delay(durations[i]);
    noTone(BUZZER_PIN);
    delay(50);              // a short gap between the notes
  }
}

void loop() {
}
```

| תו | C4 (דו) | D4 (רה) | E4 (מי) | F4 (פה) | G4 (סול) | A4 (לה) | B4 (סי) | C5 (דו) |
|------|----|----|----|----|----|----|----|----|
| תדר (Hz) | 262 | 294 | 330 | 349 | 392 | 440 | 494 | 523 |

כל אוקטבה למעלה **מכפילה** את התדר: ‏A4 הוא 440 Hz, ‏A5 הוא 880 Hz.

> **אקטיבי או פסיבי?** לזמזם **אקטיבי** (active) יש מחולל גל משלו בפנים. תנו לו HIGH קבוע והוא מצפצף, תמיד באותו צליל, ולכן הוא לא יכול לנגן תווים. זמזם **פסיבי** צריך את הגל שלכם, ומנגן כל תו שתתנו לו. אם זמזם מצפצף כשמחברים אותו ישירות ל-3.3 V, הוא אקטיבי.

## ‏3. סרוו: מחזור קבוע של 20 ms, רוחב פולס משתנה

סרוו מקשיב לעוד משהו אחר. הוא מצפה ל**פולס אחד כל 20 ms** ‏(50 Hz), ו**הרוחב של הפולס** אומר לו מה הזווית. הפריט [מנוע סרוו](topic.html?id=motors) ביחידת המנועים מסביר מה יש בתוך סרוו, איך מחברים אותו ואיך משתמשים בספריית סרוו. כאן נסתכל רק על הגל שלו:

![שלושה אותות סרוו בקנה מידה אמיתי עם מחזור של 20 ms: פולס של 0.5 ms ‏(מחזור עבודה 2.5 %) שולח את הזרוע ל-0°, ‏1.5 ms ‏(7.5 %) ל-90° ו-2.4 ms ‏(12 %) ל-180°](assets/waves/servo-pulse.svg)

כשמציירים בקנה מידה אמיתי, הפולס זעיר: הפין נמצא ב-LOW כמעט כל הזמן. מחזור העבודה הוא רק בין 2.5 % ל-12 %, והמתח הממוצע פחות מ-0.4 V. זה לא משנה, כי השבב של הסרוו **מודד את הרוחב של כל פולס** ומסובב את הזרוע בהתאם. הוא לא מרגיש ממוצע, וה-20 ms לא חייבים להיות מדויקים.

ביד, זו שוב אותה `squareWave()`:

```c
const int SERVO_PIN = D9;
const long PERIOD_US = 20000;    // 20 ms: stays the same

void setup() {
  pinMode(SERVO_PIN, OUTPUT);
}

void loop() {
  int angle = 90;                                  // change this
  long widthUs = map(angle, 0, 180, 500, 2400);    // 0.5 ms to 2.4 ms
  squareWave(SERVO_PIN, widthUs, PERIOD_US - widthUs);
}
```

**למה לא `analogWrite()`?** גם היא יוצרת פולסים ברוחב שבוחרים, אבל המחזור שלה הוא בערך 1 ms, קצר פי עשרים ממה שהסרוו צריך. ספריית סרוו משתמשת באותה חומרת PWM, כשהיא מכוונת ל-50 Hz. היא גם יוצרת את הפולסים ברקע, כך שהתוכנית שלכם פנויה לעשות דברים אחרים.

## סיכום

- לגל ריבועי יש **מחזור** `T` (או **תדר** `f = 1 / T`) ו**מחזור עבודה** (החלק מ-`T` שבו הוא גבוה).
- ‏**PWM**: מחזור קבוע וקצר ומחזור עבודה משתנה. העומס מרגיש את **ההספק הממוצע**, `duty × full power`. השתמשו ב-`analogWrite()`.
- **זמזם**: מחזור עבודה קבוע של 50 % ותדר משתנה. התדר הוא **גובה הצליל**. השתמשו ב-`tone()` וב-`noTone()`.
- **סרוו**: מחזור קבוע של 20 ms ופולס של 0.5 – 2.4 ms. **הרוחב** של הפולס הוא **הזווית**.

## אתגרים

1. **תרמין:** חברו פוטנציומטר ל-A0 (ראו את הפריט על [הפינים האנלוגיים](topic.html?id=microcontrollers)) וזמזם ל-D5. סיבוב הכפתור משנה את הצליל מ-200 Hz עד 2000 Hz. השתמשו ב-`map()`.
2. **סירנה:** גרמו לזמזם לעלות בהדרגה מ-500 Hz ל-1500 Hz ולרדת בחזרה, שוב ושוב, כמו אמבולנס.
3. **אותו כפתור, שלושה גלים:** עם אותו פוטנציומטר, קבעו בבת אחת את העוצמה של נורית ב-D2, את הצליל של הזמזם ב-D5 ואת הזווית של סרוו ב-D9. איזה מספר של הגל כל אחד מהם משנה?
