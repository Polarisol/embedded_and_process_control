# GitHub Copilot: מדריך למתחילים

בקורס שלנו אפשר להיעזר בצ'טבוטים ובסוכני בינה מלאכותית (AI agents). אחד הכלים האלה הוא GitHub Copilot, שמשולב באופן מובנה ב-VS Code (סביבת הפיתוח שלנו). הנה כמה טיפים פשוטים לשימוש בו.

#### 1. התקדמו בצעדים קטנים

* **התחילו בקטן:** אל תבקשו מ-Copilot לכתוב אפליקציה שלמה בבת אחת.

* **בדקו תוך כדי:** בקשו חתיכת קוד קטנה אחת. בדקו אותה כדי לוודא שהיא עובדת. ורק אז עברו לחתיכה הבאה.

#### 2. השתמשו ב-Git כרשת ביטחון

* **בדקו את השינויים:** תמיד הסתכלו בלשונית Git ב-VS Code. ראו בדיוק איזה קוד Copilot הוסיף או שינה.

* **שמרו לעיתים קרובות:** עשו commits קטנים ותכופים. אם Copilot עושה טעות, תוכלו בקלות לחזור לגרסה ישנה יותר.

#### 3. בקשו מ-Copilot להסביר קוד

* **אל תנחשו:** לעולם אל תשתמשו בקוד שאתם לא מבינים.

* **איך עושים את זה:** סמנו את הקוד המבלבל. לחצו עליו בכפתור הימני, בחרו **Copilot**, ולחצו על **Explain This**. Copilot יסביר לכם מה הקוד עושה בשפה פשוטה.

#### 4. השתמשו בצ'אט המשולב `Ctrl+I`

* **הישארו בתוך הקוד:** לחצו `Ctrl+I` בדיוק במקום שבו אתם מקלידים. תופיע תיבת בקשה (prompt) קטנה.

* **ראו את ההבדל:** Copilot יציג את השינויים המוצעים באדום (מה שהוסר) ובירוק (מה שנוסף). אפשר לקבל או לדחות אותם לפני שהם נכנסים סופית.

#### 5. השתמשו בחלונית הצ'אט הצדדית לשאלות גדולות

* **כמו חבר חכם:** פתחו את Copilot Chat בצד המסך.

* **סיעור מוחות:** השתמשו במקום הזה כדי לתכנן את הקוד, לשאול איך להתחיל פרויקט, או להבין למה משהו לא עובד.

#### 6. היזהרו עם ההשלמה האוטומטית

* **קודם קוראים:** Copilot יציע קוד בטקסט אפור בהיר. קראו אותו לפני שאתם לוחצים `Tab` כדי לקבל אותו.

* **מילה אחרי מילה:** לחצו `Ctrl + Right Arrow` (או `Cmd + Right Arrow`) כדי לקבל את ההצעה מילה אחת בכל פעם.

* **תגידו לא:** אם ההצעה לא מוצאת חן בעיניכם, פשוט לחצו `Esc` והיא תיעלם.
