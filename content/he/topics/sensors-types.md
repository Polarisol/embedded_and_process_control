# סוגי חיישנים

לוח פיתוח לבדו הוא כמו מוח בצנצנת: הוא יכול לחשוב מהר מאוד, אבל אין לו מושג מה קורה סביבו. **חיישנים** (sensors) הם העיניים, האוזניים והעור שלו. חיישן הופך משהו מהעולם האמיתי (לחיצה, סיבוב, אור, חום, תנועה, מרחק) ל**אות חשמלי** שהלוח יכול לקרוא.

בטלפון שלכם יש יותר מעשרה כאלה: הוא יודע מתי אתם מסובבים אותו, כמה החדר מואר, איפה אתם נמצאים ומתי אתם מצמידים אותו לאוזן. ביחידה הזו נתחיל מהחיישנים הכי פשוטים שיש, וכבר איתם אפשר לבנות אזעקות, מנורות לילה, תרמוסטטים וחיישני חניה.

## איך חיישן מדבר עם הלוח?

כל חיישן עונה באחת מארבע דרכים. ברגע שאתם יודעים באיזו דרך חיישן משתמש, אתם כבר יודעים איך לחבר אותו ואיזו פונקציה קוראת אותו.

![ארבעה סוגי אותות: דיגיטלי, אנלוגי, אורך פולס ונתונים דיגיטליים](assets/sensors/signal-types.svg)

| סוג | מה הלוח רואה | קוראים עם | דוגמאות |
|------|---------------------|--------------|----------|
| **דיגיטלי** (digital) | רק HIGH או LOW (1 או 0) | `digitalRead(pin)` | כפתור, מתג הטיה, חיישן תנועה PIR |
| **אנלוגי** (analog) | מתח כלשהו בין 0 V למתח האספקה | `analogRead(pin)` | פוטנציומטר, LDR, תרמיסטור |
| **אורך פולס** (pulse length) | כמה זמן פין נשאר HIGH | `pulseIn(pin, HIGH)` | חיישן מרחק אולטרסוני |
| **נתונים דיגיטליים** (digital data) | רצף של ביטים שמרכיב מספר | ספרייה | DHT11 / DHT22, ובהמשך חיישני I²C |

### ממתח למספר: ה-ADC

המעבד של הלוח מבין רק מספרים, ולכן פינים אנלוגיים עוברים דרך **ADC** (Analog-to-Digital Converter, ממיר אנלוגי-לדיגיטלי). הוא מודד את המתח ונותן לכם מספר שלם:

| לוח | מתח אספקה | רזולוציית ה-ADC | הטווח של `analogRead()` |
|-------|----------------|----------------|----------------------|
| Arduino Uno / Nano | 5 V | 10 ביט | 0 – 1023 |
| ESP32 | 3.3 V | 12 ביט | 0 – 4095 |

כלומר ב-Uno, 0 V נקרא כ-`0`, 5 V נקרא כ-`1023`, ו-2.5 V נקרא בערך כ-`512`.

> **לוחות ESP עובדים על 3.3 V.** אף פעם אל תכניסו 5 V לפין של ESP. הזינו את החיישנים מהפין **3.3V**, או הורידו קודם את מתח היציאה של החיישן (נראה איך עושים את זה בחיישן האולטרסוני).

## 1. כפתור לחיצה

**מה זה:** שני מגעים ממתכת וקפיץ. לוחצים - והמגעים נוגעים זה בזה; עוזבים - והקפיץ מרחיק אותם.

**משמשים ל:** מקלדות, כפתורי מעלית, שלטים של קונסולות משחק, כפתור ה"התחל" במיקרוגל, והפרויקט המשובץ הראשון שלכם אי פעם.

**איך הוא מדבר:** **דיגיטלי**. הפין קורא HIGH או LOW.

יש מלכודת אחת. כשהכפתור *לא* לחוץ, הפין לא מחובר לשום דבר, ופין שלא מחובר לשום דבר "צף" (floating): הוא קולט רעש חשמלי וקורא 1 ו-0 אקראיים. הפתרון הוא **נגד משיכה למעלה** (pull-up resistor) שמחזיק את הפין בעדינות ב-HIGH עד שהכפתור מושך אותו למטה ל-GND. גם ל-Arduino וגם ל-ESP יש נגד כזה מובנה, ו-`INPUT_PULLUP` מפעיל אותו.

![כפתור מחובר בין פין D2 ל-GND, עם נגד ה-pull-up הפנימי](assets/sensors/button.svg)

שימו לב שהתוצאה "הפוכה": **לחוץ = LOW**, משוחרר = HIGH.

```c
const int BUTTON_PIN = 2;

void setup() {
  Serial.begin(9600);
  pinMode(BUTTON_PIN, INPUT_PULLUP);   // switch on the built-in pull-up
}

void loop() {
  if (digitalRead(BUTTON_PIN) == LOW) {
    Serial.println("Pressed!");
  } else {
    Serial.println("Released");
  }
  delay(100);
}
```

**עובדה מעניינת: כפתורים קופצים.** כשמגעי המתכת פוגעים זה בזה, הם קופצים כמה פעמים במילישניות הראשונות, כך שלחיצה אחת יכולה להיראות כמו חמש לחיצות בעיני מיקרו-בקר מהיר. ההמתנה של כמה מילישניות אחרי שינוי לפני שמאמינים לו נקראת **ניקוי ריטוט** (debouncing). הפריט **כפתורים - מתקדם** מסביר את הקפיצות ואיך מתקנים אותן.

## 2. פוטנציומטר

**מה זה:** נגד עם רגל שלישית, ה**מגב** (wiper), שמחליקה לאורכו כשמסובבים את הכפתור. יש לו שלוש רגליים: שני הקצוות והמגב באמצע.

**משמש ל:** כפתורי ווליום, מעמעמי תאורה, כפתור המהירות במאוורר, וג'ויסטיקים (ג'ויסטיק הוא פשוט שני פוטנציומטרים, אחד לימין-שמאל ואחד למעלה-למטה).

**איך הוא מדבר:** **אנלוגי**. מחברים קצה אחד לאספקה, את הקצה השני ל-GND, ואת המגב לפין אנלוגי. סיבוב הכפתור מזיז את המגב מ-0 V ועד מתח האספקה. המעגל הזה נקרא **מחלק מתח** (voltage divider), ותפגשו אותו שוב ושוב.

![פוטנציומטר מחובר כמחלק מתח, כשהמגב מחובר ל-A0](assets/sensors/potentiometer.svg)

```c
void setup() {
  Serial.begin(9600);
}

void loop() {
  int value = analogRead(A0);              // 0 to 1023 on an Uno
  float volts = value * 5.0 / 1023.0;      // convert back to volts
  Serial.print(value);
  Serial.print("  ->  ");
  Serial.print(volts);
  Serial.println(" V");
  delay(200);
}
```

ב-ESP32 השתמשו בפין שתומך בקריאה אנלוגית, כמו GPIO 34 (`analogRead(34)`), ושנו את החישוב ל-`value * 3.3 / 4095.0`.

**נסו את זה:** פתחו את **Tools → Serial Plotter** ב-Arduino IDE וסובבו את הכפתור. תקבלו גרף חי של תנועת היד שלכם.

## 3. LDR (נגד תלוי אור)

**מה זה:** דיסקית קטנה עם קו מפותל למעלה. זה נגד שההתנגדות שלו **יורדת כשאור מאיר עליו**: בערך 1 kΩ באור חזק, ומאות kΩ בחושך.

**משמש ל:** פנסי רחוב שנדלקים בשקיעה, מנורות לילה, בהירות מסך אוטומטית בטלפון (טלפונים משתמשים בחיישן אור מדויק יותר, אבל הרעיון זהה) ואזעקות "האם הקופסה נפתחה?".

**איך הוא מדבר:** **אנלוגי**. הלוח לא יכול למדוד התנגדות ישירות, רק מתח. לכן מצמידים ל-LDR נגד קבוע ובונים מחלק מתח, בדיוק כמו בפוטנציומטר. כאן האור, ולא היד שלכם, מזיז את ה"מגב".

![LDR למעלה ונגד 10 kΩ למטה יוצרים מחלק מתח שנכנס ל-A0](assets/sensors/ldr.svg)

```c
const int LED_PIN = 13;
const int DARK_LEVEL = 300;    // adjust this for your room

void setup() {
  Serial.begin(9600);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int light = analogRead(A0);
  Serial.println(light);

  if (light < DARK_LEVEL) {
    digitalWrite(LED_PIN, HIGH);   // it's dark: night light ON
  } else {
    digitalWrite(LED_PIN, LOW);
  }
  delay(200);
}
```

החליפו בין ה-LDR לנגד ה-10 kΩ והקריאות יתהפכו: אור חזק ייתן אז מספר *נמוך*. אף אחת מהדרכים לא שגויה, רק תזכרו איזו מהן בניתם.

## 4. תרמיסטור

**מה זה:** נגד שמשתנה עם ה**טמפרטורה**. הסוג הנפוץ הוא **NTC** (Negative Temperature Coefficient, מקדם טמפרטורה שלילי): ככל שחם יותר, ההתנגדות שלו נמוכה יותר.

**משמש ל:** מקררים, קומקומים, ראשי הדפסה של מדפסות תלת-ממד, מנועי מכוניות, והסוללה בטלפון שלכם (שמפסיקה להיטען אם היא מתחממת יותר מדי).

**איך הוא מדבר:** **אנלוגי**, ומחובר בדיוק כמו ה-LDR: התרמיסטור למעלה, נגד קבוע באותו ערך (בדרך כלל 10 kΩ) למטה, ונקודת האמצע לפין אנלוגי. הקריאה עולה ככל שהוא מתחמם. נוסחה קצרה, או ספרייה, הופכת את המספר ל-°C.

**נסו את זה:** הריצו את הסקיצה של ה-LDR עם תרמיסטור במקומו והחזיקו אותו בין האצבעות. תראו את המספר מטפס.

## 5. מתג הטיה

**מה זה:** שפופרת קטנטנה עם כדור מתכת בפנים. כשהשפופרת עומדת זקופה, הכדור נח על שני מגעים ומחבר ביניהם. מטים אותה - והכדור מתגלגל הצידה.

**משמש ל:** צעצועים שמתעוררים כשמרימים אותם, מכונות פינבול ישנות ("TILT!"), ותנורי חימום שנכבים אם הם נופלים.

**איך הוא מדבר:** **דיגיטלי**. מחברים וכותבים לו קוד בדיוק כמו לכפתור, עם `INPUT_PULLUP`. זה כפתור שכוח הכבידה לוחץ עליו.

![תרמיסטור, מתג הטיה, חיישן תנועה PIR וחיישן טמפרטורה ולחות DHT11](assets/sensors/more-sensors.svg)

## 6. חיישן תנועה PIR

**מה זה:** PIR הם ראשי התיבות של **Passive InfraRed** (אינפרא-אדום פסיבי). כל גוף חם זוהר באור אינפרא-אדום, שהעיניים שלנו לא רואות. הכיפה הלבנה היא עדשה שמחלקת את החדר לאזורים; כשגוף חם עובר מאזור לאזור, החיישן מבחין בשינוי. הוא לא שולח שום דבר החוצה, רק צופה, ולכן הוא "פסיבי".

**משמש ל:** אורות שנדלקים כשנכנסים לחדר, אזעקות פריצה, דלתות אוטומטיות ומייבשי ידיים.

**איך הוא מדבר:** **דיגיטלי**. למודול הנפוץ HC-SR501 יש שלושה פינים: מתח, GND ו-OUT. ה-OUT עולה ל-HIGH לכמה שניות כשהוא מזהה תנועה. היציאה שלו היא 3.3 V, כך שהוא בטוח גם ללוחות ESP.

```c
const int PIR_PIN = 2;

void setup() {
  Serial.begin(9600);
  pinMode(PIR_PIN, INPUT);
}

void loop() {
  if (digitalRead(PIR_PIN) == HIGH) {
    Serial.println("Motion detected!");
  }
  delay(200);
}
```

תנו לו בערך דקה אחרי ההדלקה "ללמוד" את החדר לפני שאתם סומכים עליו. שני הכפתורים הכתומים הקטנים במודול קובעים כמה הוא רגיש וכמה זמן ה-OUT נשאר HIGH.

## 7. חיישן מרחק אולטרסוני

**מה זה:** ל-HC-SR04 יש שתי "עיניים", אבל בעצם אלה רמקול קטנטן ומיקרופון. הוא צועק צפצוף קצר ב-40 kHz, גבוה מדי בשביל שבני אדם ישמעו, ומקשיב להד, בדיוק כמו עטלף או דולפין.

**משמש ל:** חיישני חניה ברכב, רובוטים שנמנעים מקירות, מדי מפלס במכלים ומטרי מדידה בלי מגע.

**איך הוא מדבר:** **אורך פולס**. שולחים פולס של 10 µs על **TRIG**. החיישן מחזיק אז את **ECHO** ב-HIGH בדיוק כל עוד לקח לצליל לעוף לעצם ובחזרה. ככל שהפולס ארוך יותר, העצם רחוק יותר.

![החיישן האולטרסוני שולח פינג, ההד חוזר, ופין ה-ECHO נשאר HIGH לאורך זמן הנסיעה](assets/sensors/ultrasonic.svg)

```c
const int TRIG_PIN = 9;
const int ECHO_PIN = 10;

void setup() {
  Serial.begin(9600);
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
}

void loop() {
  // send a 10 µs pulse to start a measurement
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);

  long duration = pulseIn(ECHO_PIN, HIGH);   // microseconds
  float cm = duration * 0.0343 / 2;          // there and back again

  Serial.print(cm);
  Serial.println(" cm");
  delay(100);
}
```

למה מחלקים ב-2? הצליל הולך לעצם **וחוזר**, כך שהוא עובר את המרחק פעמיים.

> **אזהרה ל-ESP:** ה-HC-SR04 צריך 5 V, ופין ה-ECHO שלו עונה ב-5 V. העבירו את ה-ECHO ל-ESP דרך מחלק מתח (למשל 1 kΩ ו-2 kΩ) כדי להוריד אותו לבערך 3.3 V, או השתמשו בגרסת ה-3.3 V, ה-HC-SR04P.

## 8. חיישן טמפרטורה ולחות DHT11 / DHT22

**מה זה:** קופסה קטנה כחולה (DHT11) או לבנה (DHT22) עם חורים. בפנים יש תרמיסטור וחיישן לחות, ועוד שבב קטנטן שעושה בשבילכם את המדידה.

**משמש ל:** תחנות מזג אוויר, חממות, תרמוסטטים חכמים ובדיקה אם חדר לח מדי.

**איך הוא מדבר:** **נתונים דיגיטליים**. במקום מתח, השבב שולח הודעה של 40 ביט על חוט יחיד: לחות, טמפרטורה ו**סכום ביקורת** (checksum) כדי לתפוס שגיאות. התזמון מסובך, אז נותנים לספרייה לעשות את זה. התקינו את **"DHT sensor library" by Adafruit** מתוך ה-Library Manager.

```c
#include <DHT.h>

DHT dht(2, DHT11);    // data pin 2, sensor type DHT11 (or DHT22)

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  float temp = dht.readTemperature();   // °C
  float hum  = dht.readHumidity();      // %
  Serial.print(temp);
  Serial.print(" °C   ");
  Serial.print(hum);
  Serial.println(" %");
  delay(2000);          // the DHT11 can only measure about once a second
}
```

זו הטעימה הראשונה שלכם מחיישנים ששולחים את הקריאה שלהם כ**נתונים**. הרבה חיישנים מתקדמים (מדי תאוצה, חיישני לחץ, חיישני צבע) עובדים כך, ולעיתים קרובות על פס תקשורת דו-חוטי שנקרא **I²C**.

## דף עזר

| חיישן | מודד | סוג אות | קוראים עם |
|--------|----------|-------------|-----------|
| כפתור לחיצה | לחיצה | דיגיטלי | `digitalRead()` + `INPUT_PULLUP` |
| מתג הטיה | הטיה | דיגיטלי | `digitalRead()` + `INPUT_PULLUP` |
| PIR | תנועה של גופים חמים | דיגיטלי | `digitalRead()` |
| פוטנציומטר | מיקום הכפתור | אנלוגי | `analogRead()` |
| LDR | אור | אנלוגי (מחלק מתח) | `analogRead()` |
| תרמיסטור | טמפרטורה | אנלוגי (מחלק מתח) | `analogRead()` |
| HC-SR04 | מרחק | אורך פולס | `pulseIn()` |
| DHT11 / DHT22 | טמפרטורה ולחות | נתונים דיגיטליים | ספריית DHT |

## אתגרים

1. **הבהוב שנשלט באור:** השתמשו ב-LDR כדי לקבוע כמה מהר נורית LED מהבהבת. ככל שהחדר חשוך יותר, היא מהבהבת מהר יותר.
2. **מונה לחיצות:** הדפיסו כמה פעמים לחצו על הכפתור. האם הוא סופר יותר מפעם אחת בכל לחיצה? הוסיפו ניקוי ריטוט.
3. **חיישן חניה:** השמיעו צפצוף בבאזר מהר יותר ויותר ככל שהיד שלכם מתקרבת לחיישן האולטרסוני.
4. **אזעקת פריצה:** כשה-PIR מזהה תנועה, הבהבו LED עד שמישהו לוחץ על הכפתור.
