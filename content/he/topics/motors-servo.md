# מנוע סרוו

**סרוו** (servo) הוא קופסה קטנה עם מנוע בפנים, שאומרים לה **לאן להגיע**, ולא רק כמה מהר להסתובב. כתבו "90°" והזרוע (שנקראת **horn**) מסתובבת ל-90° ו**נשארת שם**, גם אם דוחפים אותה. סרוו התחביבים הנפוץ ביותר הוא ה-**SG90** הכחול.

## איך זה עובד

סרוו הוא בעצם ארבעה חלקים בקופסה אחת:

![הפולס מגיע לשבב בקרה, שמפעיל מנוע DC קטן, דרך גלגלי שיניים, אל הזרוע שביציאה; פוטנציומטר מודד את הזווית ומדווח בחזרה לשבב](assets/motors/servo-inside.svg)

1. **מנוע DC** קטן, שמסתובב מהר אבל חלש.
2. **גלגלי שיניים** (gears), שהופכים אותו לאיטי יותר אבל חזק הרבה יותר.
3. **פוטנציומטר** (potentiometer) (חיישן שדומה לכפתור סיבובי, כמו זה מיחידת החיישנים) שמחובר לציר היציאה. הוא מודד באיזו זווית הציר נמצא ברגע זה.
4. **שבב בקרה** שקורא את הפקודה שלכם ומשווה אותה למה שהפוטנציומטר מודד. אם הציר לא נמצא איפה שהוא צריך להיות, השבב מסובב את המנוע לכיוון הזווית הנכונה, ועוצר כשהן מתאימות.

הרעיון הזה של **למדוד ולתקן** נקרא **חוג סגור** (closed loop), או **משוב** (feedback). זה הלב של בקרת תהליכים, ועוד ניתקל בו בהמשך הקורס.

## שליטה בסרוו: הפולס

לסרוו יש **שלושה חוטים**, והפקודה מגיעה בחוט אות יחיד בתור **פולס** (pulse). הלוח שולח פולס כל **20 ms** (50 פעמים בשנייה), ו**הרוחב** של הפולס אומר מה לעשות:

![פולס של 0.5 ms שולח סרוו זוויתי ל-0°, 1.5 ms ל-90° ו-2.4 ms ל-180°; בסרוו רציף אותם פולסים אומרים מהירות מלאה לכיוון אחד, עצירה, ומהירות מלאה לכיוון השני](assets/motors/servo-pulses.svg)

לפי הספר הערכים הם 1 ms עד 2 ms, אבל רוב הסרוואים הקטנים כמו ה-SG90 משתמשים בפועל בבערך **0.5 ms עד 2.4 ms** לכל הטווח של 0° עד 180°. אם הסרוו שלכם מזמזם בקצוות, הוא נדחף אל העצירה של עצמו: השתמשו בטווח קצת יותר צר.

## סרוו זוויתי וסרוו רציף

שני סוגי הסרוו נראים בדיוק אותו דבר מבחוץ. ההבדל הוא בפנים:

| | סרוו זוויתי | סרוו רציף |
|---|---|---|
| פוטנציומטר | מחובר לציר | מנותק (או מקובע באמצע) |
| יכול להסתובב | בערך 180° | סיבובים שלמים, בלי לעצור |
| פולס של 1.5 ms אומר | לך ל-90° | **עצור** |
| פולס קצר או ארוך יותר אומר | לך לזווית קטנה או גדולה יותר | הסתובב לכיוון אחד או לשני; ככל שרחוק יותר מ-1.5 ms, יותר מהר |
| יודע איפה הוא נמצא? | כן | **לא.** אתם שולטים רק במהירות ובכיוון |
| טוב בשביל | זרועות רובוט, היגוי, דשים, מנעולים | גלגלים של רובוט קטן |

סרוו רציף "חושב" שהוא תמיד ב-90°. בקשו ממנו להגיע ל-0° והוא ימשיך להסתובב לנצח בניסיון להגיע לשם. וזה בדיוק מה שהופך אותו למנוע עם גלגלי שיניים ודרייבר מובנה שנוח מאוד לעבוד איתו.

> **טוב לדעת:** סרוו רציף אמור לעצור ב-1.5 ms, אבל הבדלים קטנים בפנים גורמים לכך שהוא עלול לזחול לאט. להרבה מהם יש בורג כיוון קטנטן כדי לתקן את זה. אם לשלכם אין, מצאו את רוחב הפולס שבו הוא עוצר (למשל 1480 µs) והשתמשו בו בתור ה"עצירה" שלכם.

## חיבור סרוו ל-Arduino Nano ESP32

| חוט הסרוו | צבע | מתחבר ל- |
|------------|--------|------------|
| מתח | **אדום** (באמצע) | **VBUS** של ה-Nano (5 V מה-USB) |
| אדמה | **חום** או שחור | **GND** של ה-Nano |
| אות | **כתום** או צהוב | **D9** של ה-Nano |

![החוט האדום של הסרוו הולך ל-VBUS, החוט הכתום ל-D9 והחוט החום ל-GND](assets/motors/servo-wiring.svg)

לסרוו יש דרייבר משלו בפנים, ולכן לא צריך מודול דרייבר. אבל:

- הזינו אותו מ-**5 V**, לא מ-3.3 V. ב-Nano ESP32 הפין **VBUS** נותן את ה-5 V שמגיעים מכבל ה-USB.
- SG90 קטן אחד מסתדר מצוין על VBUS. ל-**שני סרוואים או יותר**, או לגדולים יותר, השתמשו בספק 5 V נפרד (מארז 4 × AA, או מודול מטען טלפון של 5 V) וחברו את ה-GND שלו ל-GND של ה-Nano. סרוואים יכולים למשוך זרם גדול לרגע, והלוח עלול לעשות ריסט.
- אות ה-3.3 V מ-D9 בסדר גמור: סרוואים מבינים אותו.

## הקוד: מייצרים את הפולס בעצמנו

סרוו רוצה רק פולס כל 20 ms, אז אפשר לייצר אותו בעצמנו עם `digitalWrite()` ו-`delayMicroseconds()`. זה עובד על כל לוח, לא צריך ספרייה, ומראה בדיוק מה קורה:

```c
const int SERVO_PIN = D9;

// Send one pulse for this angle, then wait for the rest of the 20 ms.
// Call it again and again: a servo needs a pulse every 20 ms.
void servoPulse(int angle) {
  int width = map(angle, 0, 180, 500, 2400);   // in microseconds
  digitalWrite(SERVO_PIN, HIGH);
  delayMicroseconds(width);
  digitalWrite(SERVO_PIN, LOW);
  delayMicroseconds(20000 - width);
}

// Hold the servo at an angle for some time.
void servoGoTo(int angle, int ms) {
  for (int t = 0; t < ms; t += 20) {
    servoPulse(angle);
  }
}

void setup() {
  pinMode(SERVO_PIN, OUTPUT);
}

void loop() {
  servoGoTo(0, 1000);
  servoGoTo(90, 1000);
  servoGoTo(180, 1000);

  // a slow sweep back to 0°: one degree every 20 ms
  for (int angle = 180; angle >= 0; angle--) {
    servoPulse(angle);
  }
}
```

`map()` הופכת את הזווית (0 עד 180) לרוחב פולס (500 עד 2400 µs). אותו קוד מפעיל גם סרוו **רציף**: `servoGoTo(90, 2000)` עוצר אותו, `servoGoTo(0, 2000)` מסובב אותו במהירות מלאה לכיוון אחד, `servoGoTo(180, 2000)` לכיוון השני, וערכים קרובים ל-90 (כמו 80 או 100) מסובבים אותו לאט.

החיסרון הוא שבזמן שהלוח עסוק בייצור פולסים, הוא לא יכול לעשות הרבה דברים אחרים. לפרויקטים גדולים יותר, השתמשו ב**ספריית סרוו**, שמייצרת את הפולסים ברקע בעזרת חומרת ה-PWM של השבב. ל-ESP32 הספרייה הנפוצה היא **ESP32Servo** (התקינו אותה מה-Library Manager). היא נותנת לכם את `myServo.attach(pin)` ואת `myServo.write(angle)`. ב-Nano ESP32, חלק מספריות ה-ESP32 מצפות למספרי ה-GPIO של השבב עצמו במקום למספרי ה-D שמודפסים על הלוח. אם הסרוו לא זז, בחרו **Tools → Pin Numbering → By GPIO number (legacy)** והשתמשו ב-GPIO **18**, שזה הפין שמסומן D9.

## סיכום

- ב**סרוו** יש מנוע, גלגלי שיניים, פוטנציומטר ושבב בקרה. **פולס** כל 20 ms קובע את המיקום שלו: בערך 0.5 ms ל-0°, 1.5 ms ל-90° ו-2.4 ms ל-180°.
- ל**סרוו רציף** אין משוב מיקום: אותו פולס קובע את **המהירות והכיוון** שלו, ו-1.5 ms אומר עצירה.

## אתגרים

1. **סרוו שנשלט בכפתור סיבובי:** חברו פוטנציומטר ל-A0 (ראו את יחידת החיישנים) וגרמו לסרוו לעקוב אחרי הכפתור. השתמשו ב-`map()` כדי להפוך את הערך של `analogRead()` לזווית.
2. **מצאו את העצירה:** עם סרוו רציף, מצאו את רוחב הפולס המדויק (ב-µs) שבו הוא עוצר לגמרי. האם זה בדיוק 1500 µs?
