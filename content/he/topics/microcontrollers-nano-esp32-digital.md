# הפינים הדיגיטליים של Nano ESP32

פין **דיגיטלי** מכיר רק שני מצבים: **HIGH** ו-**LOW**. ב-Nano ESP32, ‏HIGH הוא **3.3 V** ו-LOW הוא **0 V**. בקוד, HIGH הוא גם `1` ו-LOW הוא `0`, אותם ביטים שפגשתם בייצוג בינארי.

שני מצבים נשמעים כמו מעט מאוד, אבל הם מספיקים כדי להדליק ולכבות נורית LED, לקרוא לחצן, לדבר עם חיישן, ואפילו לקבוע את המהירות של מנוע.

![ה-Nano ESP32 כשהפינים הדיגיטליים שלו מודגשים: D0 עד D13 בצד ימין, כש-D13 הוא נורית L ו-SPI SCK, ‏D10 עד D12 הם SPI, ‏D0 ו-D1 הם Serial0; ‏A0 עד A7 בצד שמאל עובדים גם כפינים דיגיטליים, ו-A4 ו-A5 הם I2C](assets/nano-esp32/digital-pins.svg)

## אילו פינים הם דיגיטליים?

| פינים | הערות |
|------|-------|
| **D2 – D9** | פנויים לכל מה שתרצו. התחילו מהם |
| **D10 – D13** | הם גם ערוץ ה-**SPI**, שמשמש כמה מסכים וכרטיסי SD. ‏**D13** מחובר גם ל**נורית "L"** שעל הלוח |
| **D0, D1** | הם גם הפורט הטורי של החומרה, **Serial0** (‏RX ו-TX). ה-Serial Monitor עובר דרך כבל ה-USB ולא דרך הפינים האלה, אז אפשר להשתמש בהם כשלא צריך את Serial0 |
| **A0 – A7** | הפינים האנלוגיים יכולים לעבוד גם כפינים דיגיטליים. ‏**A4** ו-**A5** הם גם ערוץ ה-**I2C**, שמשמש הרבה חיישנים |

> **כתבו את שמות הפינים כמו שהם מודפסים על הלוח:** `D2`, `D13`, `A0`. ‏Arduino מגדירים את השמות האלה עבור ה-Nano ESP32, כך שהקוד שלכם תמיד מתכוון לפין הנכון.

## מה פין דיגיטלי יכול לעשות?

לפני שמשתמשים בפין, אומרים לו מה התפקיד שלו בעזרת `pinMode()`, בדרך כלל בתוך `setup()`:

| `pinMode(pin, ...)` | התפקיד של הפין |
|---------------------|---------------|
| `OUTPUT` | הלוח קובע אם הפין יהיה HIGH או LOW |
| `INPUT` | הלוח קורא את הפין. משהו מבחוץ צריך להחזיק אותו ב-HIGH או ב-LOW |
| `INPUT_PULLUP` | קריאת הפין, עם נגד בתוך הלוח שמחזיק אותו ב-HIGH כששום דבר לא מושך אותו למטה |
| `INPUT_PULLDOWN` | קריאת הפין, עם נגד בתוך הלוח שמחזיק אותו ב-LOW כששום דבר לא מושך אותו למעלה |

יש שלושה דברים שתעשו עם פין דיגיטלי: **לכתוב** אליו, **לקרוא** ממנו, וליצור איתו **PWM**.

## 1. יציאה: `digitalWrite()`

כיציאה (output), הפין הוא מתג שמתחבר ל-3.3 V ‏(HIGH) או ל-0 V ‏(LOW). חברו נורית LED עם נגד בין הפין ל-GND, ו-HIGH ידליק אותה:

![שני מעגלים זה לצד זה: digitalWrite(D2, HIGH) שם 3.3 V על D2, זרם עובר דרך נגד של 220 אוהם ודרך הנורית אל GND והנורית דולקת; digitalWrite(D2, LOW) שם 0 V על D2 והנורית כבויה](assets/nano-esp32/digital-output.svg)

```c
const int LED_PIN = D2;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);  // 3.3 V: LED on
  delay(1000);
  digitalWrite(LED_PIN, LOW);   // 0 V: LED off
  delay(1000);
}
```

זו אותה תוכנית הבהוב מהסקירה, עם נורית שחיברתם בעצמכם במקום נורית ה-"L".

**כמה פין יכול לתת?** פין יכול לתת בבטחה בערך **20 mA**, ואף פעם לא יותר מ-40 mA. זה מספיק לנורית LED עם נגד, לזמזם או לכניסה של שבב אחר. זה **לא** מספיק למנוע, לממסר או לפס של נוריות. בשבילם, הפין מפעיל **MOSFET** או דרייבר שעושה את העבודה הכבדה (ראו את הפריט [MOSFETs](topic.html?id=electronics) ביחידת אלקטרוניקה).

## 2. כניסה: `digitalRead()`

ככניסה (input), הפין מודד את המתח עליו ומחליט אם הוא HIGH או LOW. ‏`digitalRead(pin)` מחזיר `HIGH` או `LOW`.

![משמאל: סולם מתח שבו מעל בערך 2.5 V נקרא HIGH, מתחת לבערך 0.8 V נקרא LOW, והתחום שביניהם לא ברור. מימין: עם INPUT_PULLUP, נגד בתוך הלוח מושך את D2 ל-3.3 V; לחצן מחבר את D2 ל-GND, כך שלחצן משוחרר נקרא HIGH ולחצן לחוץ נקרא LOW](assets/nano-esp32/digital-input.svg)

- מעל בערך **2.5 V** הפין קורא **HIGH**.
- מתחת לבערך **0.8 V** הוא קורא **LOW**.
- באמצע, התוצאה לא ברורה ויכולה להשתנות מקריאה לקריאה. מעגל טוב אף פעם לא משאיר פין שם.

**פין שלא מחובר לשום דבר "מרחף" (floats).** הוא קולט רעש חשמלי וקורא HIGH ו-LOW אקראיים. בגלל זה מחברים לחצן עם נגד **pull-up** (או pull-down). ל-Nano ESP32 יש את שניהם בתוך כל פין, אז לא צריך להוסיף נגד: `INPUT_PULLUP` מפעיל אותו. חברו את הלחצן בין הפין ל-GND. כשהלחצן משוחרר, ה-pull-up מחזיק את הפין ב-HIGH. כשהוא לחוץ, הלחצן מחבר את הפין ל-GND והוא קורא LOW.

התוכנית הזו מדליקה את הנורית שעל D2 כל עוד הלחצן שעל D3 לחוץ:

```c
const int LED_PIN = D2;
const int BUTTON_PIN = D3;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  pinMode(BUTTON_PIN, INPUT_PULLUP);   // switch on the pull-up inside the board
}

void loop() {
  if (digitalRead(BUTTON_PIN) == LOW) {   // pressed = LOW
    digitalWrite(LED_PIN, HIGH);
  } else {
    digitalWrite(LED_PIN, LOW);
  }
}
```

הפריטים לחצן ולחצנים מתקדם ביחידת [חיישנים](topic.html?id=sensors) מעמיקים בלחצנים, בהקפצות (bouncing) ובסינון שלהן (debouncing).

## 3. ‏PWM: ‏`analogWrite()`

פין דיגיטלי יכול להיות רק 3.3 V או 0 V. אז איך גורמים לנורית לזהור **בחצי** עוצמה, או למנוע להסתובב בחצי מהירות? מדליקים ומכבים את הפין מהר מאוד, בערך אלף פעמים בשנייה. זה נקרא **PWM** ‏(Pulse Width Modulation, אפנון רוחב פולס), והחלק מהזמן שבו הפין דולק נקרא **מחזור העבודה** (duty cycle).

![אותות PWM עם 25 %, 50 % ו-100 % זמן הדלקה, ערכי analogWrite שיוצרים אותם, ומהירות המנוע המתאימה](assets/motors/pwm.svg)

העין שלכם (או המנוע) איטית מכדי לראות כל פולס, אז היא מרגישה את **הממוצע**. ‏25 % דולק נראה עמום, 100 % דולק הוא עוצמה מלאה. בקוד, `analogWrite(pin, value)` יוצר את אות ה-PWM, כש-`value` נע בין **0** (תמיד כבוי) ל-**255** (תמיד דולק). התוכנית הזו גורמת לנורית להתבהר ולהתעמעם:

```c
const int LED_PIN = D2;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  for (int value = 0; value <= 255; value++) {   // fade in
    analogWrite(LED_PIN, value);
    delay(5);
  }
  for (int value = 255; value >= 0; value--) {   // fade out
    analogWrite(LED_PIN, value);
    delay(5);
  }
}
```

ב-Nano ESP32, **כל פין D יכול ליצור PWM**, ועד 8 פינים יכולים לעשות את זה בו-זמנית. אל תתנו לשם `analogWrite` לבלבל אתכם: הפין עדיין נותן רק 3.3 V או 0 V. הפריט על הפינים האנלוגיים מסביר למה.

## שמרו על הלוח שלכם בחיים

- **אף פעם אל תחברו לפין יותר מ-3.3 V.** חיישן או מודול של 5 V צריך קודם מחלק מתח או ממיר רמות (level shifter).
- **אף פעם אל תחברו פין יציאה ישירות ל-GND או ל-3V3.** כשהפין מנסה להיות HIGH והוא מחובר ל-GND, הוא נותן הרבה יותר מ-40 mA ונהרס. תמיד צריך להיות עומס בדרך (כמו נורית LED עם הנגד שלה).
- **מנועים, ממסרים וכל דבר גדול עוברים דרך MOSFET או דרייבר,** אף פעם לא ישירות על הפין.

## סיכום

- פין דיגיטלי הוא **HIGH ‏(3.3 V)** או **LOW ‏(0 V)**. קובעים את התפקיד שלו עם `pinMode()`.
- ‏`digitalWrite(pin, HIGH/LOW)` קובע יציאה. פין נותן עד בערך **20 mA**.
- ‏`digitalRead(pin)` קורא כניסה. השתמשו ב-`INPUT_PULLUP` כדי שפין של לחצן אף פעם לא ירחף.
- ‏`analogWrite(pin, 0–255)` יוצר **PWM** על כל פין D, כדי לעמעם נורית או לקבוע את המהירות של מנוע.

## אתגר

**רמזור:** חברו נורית אדומה, צהובה וירוקה (כל אחת עם נגד משלה) ל-D2, ‏D3 ו-D4. גרמו להן לעבוד כמו רמזור אמיתי. אחר כך הוסיפו לחצן על D5: כשמישהו לוחץ עליו, הרמזור מסיים את המחזור שלו ועובר לאדום כדי שהולך רגל יוכל לחצות.
