# חיישן תנועה PIR

**מה זה:** PIR הם ראשי התיבות של **Passive InfraRed** (אינפרא-אדום פסיבי). כל גוף חם זוהר באור אינפרא-אדום, שהעיניים שלנו לא רואות. הכיפה הלבנה היא עדשה שמחלקת את החדר לאזורים; כשגוף חם עובר מאזור לאזור, החיישן מבחין בשינוי. הוא לא שולח שום דבר החוצה, רק צופה, ולכן הוא "פסיבי".

**משמש ל:** אורות שנדלקים כשנכנסים לחדר, אזעקות פריצה, דלתות אוטומטיות ומייבשי ידיים.

**איך הוא מדבר:** **דיגיטלי**. למודול הנפוץ HC-SR501 יש שלושה פינים: מתח, GND ו-OUT. ה-OUT עולה ל-HIGH לכמה שניות כשהוא מזהה תנועה. היציאה שלו היא 3.3 V, כך שהוא בטוח גם ללוחות ESP.

![חיישן תנועה PIR](assets/sensors/pir.svg)

```c
const int PIR_PIN = 2;

void setup() {
  Serial.begin(9600);
  pinMode(PIR_PIN, INPUT);
}

void loop() {
  if (digitalRead(PIR_PIN) == HIGH) {
    Serial.println("Motion detected!");
  }
  delay(200);
}
```

תנו לו בערך דקה אחרי ההדלקה "ללמוד" את החדר לפני שאתם סומכים עליו. שני הכפתורים הכתומים הקטנים במודול קובעים כמה הוא רגיש וכמה זמן ה-OUT נשאר HIGH.

## אתגר

**אזעקת פריצה:** כשה-PIR מזהה תנועה, הבהבו LED עד שמישהו לוחץ על הכפתור.
