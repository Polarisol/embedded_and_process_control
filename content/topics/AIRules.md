# Rules for using AI

In this course it is permitted to use chat bots and AI agents, but the usage should be in a way that leaves us in full control, and with a clear understanding of what the code is doing and how.

If we **vibe code** our project, we have no idea what is going on inside, if things are exactly the way they should be and how things are done. This is sometimes fine for personal projects or project that are not that important, but it is not fine for serious or professional work.

Scientists and Engineers need to be able to say exactly how the app does its job, and know how to tinker and modify it themselves. They are responsible for what the app does and how it behaves. They do not **believe** that the program works in a certain way, they **know** it for certain.

So, in order to be in control we must understand the coding language. It might suprise you to know that you do not need to be a programming expert to achieve this. Even a basic understanding of the language can give you the power to verify, modify, and control the code effectively.

You also need to be familiar with different tools and technologies, with some algorithms and protocols, and understand the way they work, so that you can effectivly steer and control the development process. You won't be able to prompt in a way that leaves you in full control if you lack this foundational knowledge.

When AI writes code for you, always review it carefully. Make sure you understand what each part of the code does, and verify that it behaves as expected before integrating it into your project.

Also, don't ask AI to write complete features for you. Break down your project into smaller tasks, and tackle them one at a time. This way, you can maintain control and understanding of each part of your project.

You should know the structure of your code, what each file is for, and where to go to change and modify different parts of your project. Many times it is much faster to tweak the code by yourself than to write extensive prompts for AI to generate the changes.

Remember, the goal is not to avoid using AI tools, but to use them wisely and responsibly, ensuring that you remain the one in control of your project at all times.

## summary in points:

- Understand the coding language to maintain control over your project.
- Be familiar with tools, technologies, algorithms, and protocols relevant to your work, and understand how they function.
- Always review AI-generated code carefully before integrating it.
- Break down projects into smaller tasks rather than asking AI to complete entire features.
- Know the structure of your code and where to make modifications.
- Use AI tools wisely and responsibly, ensuring you remain in control at all times.
