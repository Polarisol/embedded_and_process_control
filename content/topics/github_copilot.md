# GitHub Copilot: A Beginner's Guide

In our course we can use chatbots and AI agents to assist us. One such tool is GitHub Copilot which is integrated natively into VS Code (our development environment). Here are simple tips for using it.

#### 1. Take Small Steps

* **Start small:** Don't ask Copilot to write a whole app at once.

* **Test as you go:** Ask for one small piece of code. Test it to make sure it works. Then move to the next piece.

#### 2. Use Git as Your Safety Net

* **Check the changes:** Always look at the Git tab in VS Code. See exactly what code Copilot added or changed.

* **Save often:** Make small, frequent commits. If Copilot makes a mistake, you can easily go back to an older version.

#### 3. Ask Copilot to Explain Code

* **Don't guess:** Never use code if you don't understand it.

* **How to use:** Highlight the confusing code. Right-click it, select **Copilot**, and click **Explain This**. Copilot will tell you what the code does in plain English.

#### 4. Use Inline Chat `Ctrl+I`

* **Stay in your code:** Press `Ctrl+I` right where you are typing. A small prompt will appear.

* **See the difference:** Copilot will show proposed changes in red (removed) and green (added). You can accept or reject them before they become permanent.

#### 5. Use the Chat Sidebar for Big Questions

* **Like a smart friend:** Open the Copilot Chat on the side of your screen.

* **Brainstorm:** Use this space to plan your code, ask how to start a project, or figure out why something is broken.

#### 6. Be Careful with Auto-Complete

* **Read first:** Copilot will suggest code using light gray text. Read it before you press `Tab` to accept it.

* **Go word by word:** Press `Ctrl + Right Arrow` (or `Cmd + Right Arrow`) to accept the suggestion one word at a time.

* **Say no:** If you don't like the suggestion, just press `Esc` to make it go away.
