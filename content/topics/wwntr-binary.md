# * What We Need to Remember

1. Understanding how to read a simple positive binary number.

2. Understand that all data, movies, music, solidworks files, and any other types of data are represented in binary form within a computer.

2. Remember that a Byte is composed of 8 bits and that it is the smallest unit of memory in a computer.

3. Computer variables take 1 Byte, 2 Bytes, 4 Bytes, or 8 Bytes depending on their type.

4. Unsigned binary numbers represent only non-negative values (0 and positive numbers), so for example an 8 bit unsigned binary number can represent values from 0 to 255.

5. Signed binary numbers can represent both negative and positive values, typically using the two's complement representation. For example, an 8-bit signed binary number can represent values from -128 to 127.

6. We need to be able to calculate the amount of Bytes (1, 2, 4, or 8) required for a given integer variable you need and decide which integer type to use.

7. Understand the difference between float and double so you can choose the appropriate type for representing decimal numbers in your programs.
