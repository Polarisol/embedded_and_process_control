# * What we need to remember

1. What is IP, what it does well and what it doesn't.

2. IPv4 addresses, structure, why there is a shortage of them.

3. LAN and WAN solution to the IPv4 address shortage.

4. IPv6 - just know that it exists and how it fixes the IPv4 address shortage.

5. TCP, how it comes to the rescue for reliable communication over IP.

6. TCP ports, what they are and why they are needed.

7. TCP server client model, how the server listens on a port and the client connects to it.

8. Understand how the event loop of PySide6 is utilized in TCP client and server implementations.

9. TCP client implementation in PySide6, you don't need to remember how to write the lines of code in great detail, but you do need to understand the signals and the way we connect to a server, send and receive data.

10. TCP server implementation in PySide6, similar to the client, but it listens on a port and handles incoming connections. how it deals with several clients.

11. You should be able to look at a code snippet from a simple tcp client or server implementation in PySide6, and understand what it does and how it works.
